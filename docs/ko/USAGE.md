# 사용법

> 기계 번역을 바탕으로 한 번역입니다. [영어판](../USAGE.md)과 내용이 다르면 영어판이 우선합니다. 수정 제안을 환영합니다: [이슈 열기](https://github.com/critterbyte/hearthstone_xp_tracker/issues/new/choose).

플러그인은 세 부분으로 이루어져 있습니다.

- 게임 안의 **오버레이**
- **대시보드** 창
- **게임 기록** 파일

"경험치 시간:"처럼 따옴표 안의 글은 플러그인이 표시하는 글입니다.

<a id="overlay"></a>
## 오버레이

오버레이는 오른쪽 아래, 하스스톤 설정 버튼(오른쪽 아래 구석의 톱니바퀴) 위에 있는 작은 상자입니다. 대시보드에서 왼쪽 아래, 내 초상화(등급이 표시된 "You") 위로 옮길 수도 있습니다. 왼쪽에는 항목 이름이, 오른쪽에는 파란 막대 안에 값이 표시됩니다.

오버레이는 **등급전, 일반전, 선술집 난투, 투기장**에서만 표시됩니다. 다른 모드는 아직 측정하지 않았으므로 플러그인이 아무것도 표시하지 않습니다. 컴퓨터를 상대로 하는 선술집 난투(PvE, 예: 여관주인 상대)는 경험치를 주지 않으므로 오버레이에 "+0"이 표시됩니다.

<a id="during-a-game"></a>
### 게임 중

각 줄은 첫 턴에 나타납니다. 시작 카드를 고르는 동안에는 오버레이가 숨겨집니다.

| 줄 | 의미 |
|---|---|
| "경험치 시간:" | 지금까지 경험치에 반영된 시간(분과 초) |
| "승리 시:" | 지금 이기면 받는 경험치 |
| "패배 시:" | 지금 지거나 항복하면 받는 경험치 |

경험치 시간에는 표시가 붙을 수 있습니다.

| 표시 | 의미 |
|---|---|
| "(일시 정지)" | 아무 행동 없이 내 턴 시간이 다 지났습니다. 그 턴과 상대의 다음 턴은 반영되지 않으므로 경험치 시간이 뒤로 돌아가 멈춰 있습니다. 내 다음 턴에 다시 흐릅니다. |
| "(최대)" | 경험치 시간이 30분에 도달했습니다. 시간이 더 지나도 경험치가 늘지 않습니다. |

하스스톤 이벤트 기간에는 대시보드에서 "이벤트 진행 중(이벤트 경험치 표시)"를 켜세요. 그러면 오버레이에 줄이 하나 더 생기며, 게임 중과 게임 후 요약에 표시됩니다.

| 줄 | 의미 |
|---|---|
| "이벤트 경험치:" | 지금까지의 이벤트 경험치(빨간 수정 표시). 경험치 시간 1분당 1입니다([FORMULA.md](../FORMULA.md#event-xp) 참고). 결과와는 관계가 없습니다. |

이벤트가 끝나면 끄세요.

대시보드에서 "선술집 패스(경험치 보너스)"를 켜면 "승리 시:", "패배 시:", "획득:"에 보상의 길 레벨에 따른 패스 보너스가 포함됩니다. 이벤트 경험치에는 보너스가 붙지 않습니다.

마지막 두 줄은 피해를 표시하며, 게임 중과 게임 후 요약에 나타납니다. 대시보드의 "오버레이에 피해 표시"로 끌 수 있습니다.

| 줄 | 의미 |
|---|---|
| "전체 피해:" | 지금까지 내 편이 상대 영웅과 하수인에게 준 모든 피해입니다. 내 공격, 내 하수인의 공격, 주문, 무기, 영웅 능력, 그 밖의 효과가 포함됩니다. 각 타격은 게임에 표시되는 수치로 계산하며, 대상의 생명력보다 크거나 방어도에 맞은 경우에도 마찬가지입니다. 내 영웅이나 하수인이 받은 피해는 계산하지 않으며, 탈진처럼 출처가 없는 피해도 계산하지 않습니다. 천상의 보호막에 맞은 타격은 0입니다. |
| "영웅 피해:" | "전체 피해:" 중 상대 영웅에게 맞은 부분이며, 방어도가 흡수한 부분도 포함합니다 |

피해는 서버가 행동을 확정할 때 읽으므로 게임판의 애니메이션보다 조금 먼저 올라갈 수 있습니다.

경험치 시간이 60초 미만인 동안에는 두 경험치 값 모두 "+0"으로 표시됩니다. 1분 미만인 게임은 경험치를 주지 않습니다. 규칙은 [FORMULA.md](../FORMULA.md)를 참고하세요.

게임 도중에 HDT를 시작해도 플러그인은 게임을 처음부터 읽습니다.

<a id="after-a-game"></a>
### 게임 후

게임이 끝나면 다음 게임의 시작 카드 단계까지 오버레이에 요약이 표시됩니다.

| 줄 | 의미 |
|---|---|
| "지난 게임:" | "승리" 또는 "패배" |
| "경험치 시간:" | 경험치에 반영된 시간 |
| "전체 시간:" | 시작 카드 단계를 포함한 게임 전체 시간 |
| "획득:" | 그 게임에서 받은 경험치 |

<a id="update-hint"></a>
### 업데이트 알림

플러그인의 새 버전이 있으면 게임을 하지 않는 동안 오버레이에 줄이 하나 더 표시됩니다.

| 줄 | 의미 |
|---|---|
| "업데이트 있음:" | 새 버전 번호. 예: 0.2.0 |

대시보드에는 다운로드 페이지 링크가 표시됩니다. 업데이트 방법은 [INSTALL.md](INSTALL.md#update)를 참고하세요.

<a id="dashboard"></a>
## 대시보드

대시보드 창의 이름은 "HS XP Tracker"입니다. HDT에서 다음 두 가지 방법 중 하나로 엽니다.

- *Plugins* 메뉴 → "경험치 대시보드"
- *Settings*(상단 바 오른쪽의 톱니바퀴 아이콘) *→ Tracker → Plugins* → 플러그인의 "경험치 대시보드" 버튼

<a id="toolbar"></a>
### 도구 모음

| 컨트롤 | 의미 |
|---|---|
| "세션" | 현재 하스스톤 세션의 게임입니다. 게임을 시작한 때부터 종료할 때까지입니다. 하스스톤을 닫은 뒤에도 다음에 시작할 때까지 마지막 세션이 계속 보입니다. 대시보드를 열면 이 기간이 표시됩니다. |
| "오늘" | 자정 이후의 게임 |
| "이번 주" | 월요일 00:00 이후의 게임 |
| "이번 시즌" | 이번 달 1일 이후의 게임. 하스스톤의 등급전 시즌은 달력 기준 한 달 동안 진행됩니다. |
| "최근 30일" | 오늘을 포함한 최근 30일의 게임 |
| "전체 기간" | 기록에 있는 모든 게임 |
| "새로 고침" | 기록을 다시 읽습니다 |
| "데이터 폴더 열기" | 기록 파일이 있는 폴더를 Windows 파일 탐색기에서 엽니다 |
| "언어 (Language)" | 오버레이, 대시보드, 플러그인 메뉴 항목의 언어입니다. 기본값은 영어입니다. 변경은 바로 적용되며, 대시보드가 새 언어로 다시 열립니다. 영어가 아닌 언어에서는 이름에 영어 단어가 함께 남습니다. 예: "언어 (Language)" |
| "오버레이 위치" | 오버레이가 표시되는 곳입니다. "오른쪽(설정 버튼 위)"(기본값) 또는 "왼쪽(내 초상화 위)"(오른쪽의 HDT 덱 목록을 가리지 않음). 바로 이동합니다. |
| "이벤트 진행 중(이벤트 경험치 표시)" | 하스스톤 이벤트 기간에 켜세요. 오버레이에 이벤트 경험치가 표시되고 새 게임에 저장됩니다. |
| "선술집 패스(경험치 보너스)" | 현재 확장팩의 선술집 패스가 있으면 켜세요. 보너스는 측정한 값이 아니라 계산한 값입니다. 패스가 있으면 표시되는 경험치가 게임당 1만큼 다를 수 있습니다([FORMULA.md](../FORMULA.md#tavern-pass) 참고). |
| "레벨"과 "−", 숫자, "+" | 보상의 길 레벨입니다. "−"나 "+"를 클릭하거나 숫자를 입력하세요. 아래 줄에 보너스와 다음 단계가 표시됩니다. 예: "경험치 보너스 10%, 15%까지 2레벨". 보너스는 10%이고, 20레벨부터 15%, 70레벨부터 20%입니다([FORMULA.md](../FORMULA.md#tavern-pass) 참고). 20레벨이나 70레벨을 넘으면 레벨을 바꿔 주세요. |
| "오버레이에 피해 표시" | "전체 피해:"와 "영웅 피해:" 줄을 표시하거나 숨깁니다. 기본값은 켜짐입니다. |
| "HDT 시작 시 업데이트 확인" | 업데이트 확인을 켜거나 끕니다. [개인 정보](#privacy)를 참고하세요. |

끝난 게임은 열려 있는 대시보드에 자동으로 나타납니다. "새로 고침"을 클릭할 필요가 없습니다.

"세션"을 고르면 도구 모음 아래 줄에 세션이 표시됩니다. 예: "화 2026-11-10, 19:56부터 세션(진행 중)" 또는 "(종료)". 세션은 자정을 넘겨 이어질 수 있습니다.

<a id="tabs"></a>
### 탭

**개요**

| 타일 | 의미 |
|---|---|
| "경험치" | 기간 동안 얻은 경험치 |
| "경험치 시간" | 경험치에 반영된 시간 |
| "플레이 시간(시작 카드 포함)" | 시작 카드 단계를 포함한 게임 시간 |
| "접속 시간" | 하스스톤이 실행되던 시간. 아래를 참고하세요. |
| "게임" | 게임 수와 승패 |
| "시간당 경험치" | 경험치 시간 1시간당 경험치 |
| "접속 시간당 경험치" | 접속 시간 1시간당 경험치. 메뉴와 대기 시간을 포함합니다 |
| "승률" | 이긴 게임의 비율 |
| "이벤트 경험치" | 기간 동안의 이벤트 경험치. 이벤트 기간에 플레이한 게임이 있을 때만 표시됩니다 |

접속 시간은 하스스톤 세션마다 계산합니다. 하스스톤을 시작한 때부터 마지막 게임이 끝날 때까지입니다. 하스스톤이 실행 중이면 현재까지 계산합니다. 기간 안에 게임이 하나 이상 있는 세션만 계산합니다.

**덱**

덱마다 한 줄입니다. 게임 수, 승률, 경험치, 시간당 경험치, 평균 게임 시간이 표시됩니다. 시간당 경험치가 가장 높은 덱이 맨 위에 있습니다.

덱 이름은 HDT 자체 통계에서 가져옵니다. HDT가 기록하지 않은 게임에는 "기록된 덱 없음"이 표시됩니다.

**잃은 경험치**

| 타일 | 의미 |
|---|---|
| "자리 비움 턴" | 자리 비움 턴 때문에 잃은 경험치. 아무 행동도 "턴 종료"도 없이 시간이 다 지난 턴과, 그 뒤의 상대 턴입니다 |
| "1분 미만 게임" | 60초 미만인 게임에 대해 공식상 받을 수 있지만 게임이 주지 않는 경험치 |
| "게임 외 시간" | 게임 밖에서 보낸 접속 시간(메뉴, 대기, 휴식). 기간의 시간당 경험치로 환산합니다 |

**게임**

기간의 모든 게임이 최신순으로 표시됩니다. 날짜, 시작, 모드, 결과, 경험치 시간, 전체 시간, 경험치, 이벤트 경험치, 자리 비움 턴, 덱, 상대 직업입니다. 열 머리글을 클릭하면 정렬됩니다.

**그래프**

같은 시간축에 곡선 두 개를 표시합니다. 시간축은 항상 기간 전체를 다루므로 게임이 없는 시간이나 날짜도 보입니다.

| 기간 | 시간축 |
|---|---|
| "세션" | 세션 시작부터 끝까지(진행 중이면 현재까지) 매시간 |
| "오늘" | 하루 24시간 |
| "이번 주" | 월요일부터 일요일까지 |
| "이번 시즌" | 이번 달의 매일 |
| "최근 30일" | 오늘을 포함한 최근 30일 |
| "전체 기간" | 기록의 첫 게임 이후 매일 |

| 곡선 | 의미 |
|---|---|
| "획득 경험치"(금색) | 각 시간 또는 각 날짜에 시작한 게임의 경험치. 게임이 없는 구간은 0입니다. |
| "시간당 경험치"(파란색) | 각 시간 또는 각 날짜의 속도: 경험치를 경험치 시간으로 나눈 값입니다. 게임이 있는 구간에만 점이 있습니다. 점선은 전체 기간의 평균입니다. |

게임은 시작한 시간이나 날짜에 계산됩니다.

<a id="game-history-file"></a>
## 게임 기록 파일

끝난 게임은 모두 CSV 파일에 추가됩니다.

```
%APPDATA%\HearthstoneDeckTracker\XpTracker\hs_games.csv
```

이 파일은 필드 구분에 쉼표를, 소수점에 마침표를 씁니다. 시각은 현지 시각입니다.

| 열 | 내용 |
|---|---|
| `Session` | 세션에 해당하는 하스스톤 로그 폴더 이름. 예: `Hearthstone_2026_11_08_09_10_51` |
| `Start` | 첫 턴의 시작, `yyyy-MM-ddTHH:mm:ss.fff` |
| `End` | 게임의 끝, 같은 형식 |
| `Mode` | 게임 모드. 예: `Ranked` |
| `Format` | 방식. 예: Standard 또는 Wild. 방식이 없는 모드에서는 비어 있습니다 |
| `Result` | 예: `Win` 또는 `Loss` |
| `XpSeconds` | 경험치에 반영된 시간 |
| `PlaySeconds` | 첫 턴부터 끝까지의 시간(자리 비움 턴 포함) |
| `WithMulliganSeconds` | 시작 카드 단계를 포함한 시간 |
| `AfkTurns` | 내 자리 비움 턴의 수 |
| `Xp` | 플러그인이 계산한 경험치. 측정한 비율이 없는 모드에서는 비어 있습니다 |
| `Deck` | HDT의 덱 이름 |
| `PlayerClass` | 내 직업 |
| `OpponentClass` | 상대의 직업 |
| `EventXp` | 플러그인이 계산한 이벤트 경험치. 이벤트 기간이 아닌 게임에서는 비어 있습니다. 이 열이 없는 이전 버전의 파일도 읽을 수 있으며, 다음 게임에서 열이 추가됩니다. |
| `XpBonus` | 게임을 플레이할 때 적용된 선술집 패스 경험치 보너스(퍼센트). 예: `15`. 패스가 없으면 `0`. 이 열이 없는 이전 파일은 `0`으로 읽습니다. |

`Xp` 열은 플러그인이 경험치 시간으로 계산한 값입니다. 게임 자체는 경험치를 로그에 남기지 않습니다. 대시보드를 열면 플러그인은 저장된 모든 게임의 경험치를 현재 비율로 다시 계산합니다. 그래서 비율이 수정되면 이전 게임도 바로잡힙니다. 각 게임은 자기 `XpBonus`를 그대로 가지므로, 나중에 패스나 레벨을 바꿔도 이전 게임은 바뀌지 않습니다.

같은 로그에서 두 번 읽은 게임은 한 번만 저장됩니다. 플러그인 새 버전을 설치해도 파일은 유지됩니다.

## 개인 정보

- 게임 기록과 설정은 내 컴퓨터에만 남습니다. 플러그인은 아무것도 업로드하지 않습니다.
- 네트워크 요청은 업데이트 확인뿐입니다. HDT가 시작될 때 플러그인이 GitHub에 새 릴리스가 있는지 한 번 묻습니다. 요청에는 플러그인 이름과 버전만 담깁니다. 예: `HearthstoneXpTracker/0.1.0`. 다른 웹 요청과 마찬가지로 GitHub는 IP 주소를 볼 수 있습니다.
- 업데이트 확인을 끄려면 대시보드에서 "HDT 시작 시 업데이트 확인"의 선택을 해제하세요. 이 설정은 `%APPDATA%\HearthstoneDeckTracker\XpTracker\settings.ini`에 저장됩니다.
