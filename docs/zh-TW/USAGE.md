# 使用方式

> 本文為機器輔助翻譯。如與[英文版](../USAGE.md)有出入，以英文版為準。歡迎指正：[提出 issue](https://github.com/critterbyte/hearthstone_xp_tracker/issues/new/choose)。

外掛程式有三個部分：

- 對戰中的**覆蓋層**
- **儀表板**視窗
- **對戰記錄**檔

引號中的文字，例如「經驗值時間：」，就是外掛程式顯示的文字。

<a id="overlay"></a>
## 覆蓋層

覆蓋層是一個小方框，位於右下角爐石戰記設定按鈕（右下角的齒輪）上方。你也可以在儀表板中把它移到左下角你的頭像（顯示你的階級的「You」）上方。標籤在左邊，數值在右邊的藍色長條中。

覆蓋層只會在**排名模式、休閒模式、旅店大亂鬥和競技場**中顯示。其他模式尚未實測，所以外掛程式在那些模式中不會顯示任何內容。對抗電腦的旅店大亂鬥（PvE，例如對抗旅店老闆）不會給經驗值，所以覆蓋層在那裡會顯示「+0」。

<a id="during-a-game"></a>
### 對戰中

這些行會在第一個回合出現。在選擇起手的手牌時，覆蓋層會隱藏。

| 行 | 意義 |
|---|---|
| 「經驗值時間：」 | 到目前為止計入經驗值的時間，以分和秒表示 |
| 「獲勝時：」 | 如果你現在獲勝，會得到的經驗值 |
| 「落敗時：」 | 如果你現在落敗或投降，會得到的經驗值 |

經驗值時間可能帶有註記：

| 註記 | 意義 |
|---|---|
| 「（暫停）」 | 你讓回合時間耗盡，卻沒有做任何動作。這個回合和對手的下一個回合都不計入，所以經驗值時間會往回跳並等待。它會在你的下一個回合再次開始計算。 |
| 「（上限）」 | 經驗值時間已達 30 分鐘。更多時間不會再給更多經驗值。 |

在爐石戰記事件期間，請在儀表板中開啟「事件進行中（顯示事件經驗值）」。覆蓋層就會多顯示一行，在對戰中即時顯示，也會顯示在對戰結束後的摘要中：

| 行 | 意義 |
|---|---|
| 「事件經驗值：」 | 到目前為止的事件經驗值，旁邊有紅色水晶：每分鐘經驗值時間 1 點（請見 [FORMULA.md](../FORMULA.md#event-xp)）。它與勝負無關。 |

事件結束時，請將它關閉。

在儀表板中開啟「旅店貴賓證（經驗值加成）」後，「獲勝時：」、「落敗時：」和「獲得：」都會包含依你的獎勵軌跡等級計算的貴賓證加成。事件經驗值沒有加成。

最後兩行顯示傷害，在對戰中即時顯示，也會顯示在對戰結束後的摘要中。你可以在儀表板中用「在覆蓋層顯示傷害」將它們關閉。

| 行 | 意義 |
|---|---|
| 「總傷害：」 | 到目前為止你這一方對對手英雄和手下造成的所有傷害：你的攻擊、你的手下的攻擊、法術、武器、英雄技能和其他效果。每次命中都以遊戲顯示的數值計算，即使超過目標的生命值或打在護甲上也一樣。對你自己的英雄或手下造成的傷害不計入，沒有來源的傷害（例如疲倦）也不計入。命中聖盾術的傷害為 0。 |
| 「英雄傷害：」 | 「總傷害：」中命中對手英雄的部分，包含被護甲吸收的部分 |

傷害會在伺服器確認動作時讀取，所以可能會比場上的動畫早一點增加。

經驗值時間低於 60 秒時，兩個經驗值數值都會顯示「+0」。不到一分鐘的對戰不會給經驗值。規則請見 [FORMULA.md](../FORMULA.md)。

如果你在對戰中途啟動 HDT，外掛程式仍會從開頭讀取這場對戰。

<a id="after-a-game"></a>
### 對戰後

對戰結束後，覆蓋層會顯示摘要，直到你下一場對戰選擇起手的手牌時為止：

| 行 | 意義 |
|---|---|
| 「上一場：」 | 勝利或落敗 |
| 「經驗值時間：」 | 計入經驗值的時間 |
| 「總時間：」 | 整場對戰的時間，包含選擇起手的手牌 |
| 「獲得：」 | 這場對戰給的經驗值 |

<a id="update-hint"></a>
### 更新提示

外掛程式有新版本時，覆蓋層會在沒有對戰進行時多顯示一行：

| 行 | 意義 |
|---|---|
| 「有可用更新：」 | 新版本的版本號，例如 0.2.0 |

儀表板會顯示下載頁面的連結。更新方式請見 [INSTALL.md](INSTALL.md#update)。

<a id="dashboard"></a>
## 儀表板

儀表板視窗的名稱是「HS XP Tracker」。在 HDT 中可以用以下兩種方式之一開啟它：

- *Plugins* 選單 →「經驗值儀表板」
- *Settings*（頂端列右側的齒輪圖示）*→ Tracker → Plugins* → 外掛程式的「經驗值儀表板」按鈕

<a id="toolbar"></a>
### 工具列

| 控制項 | 意義 |
|---|---|
| 「本次工作階段」 | 目前爐石戰記工作階段的對戰，從遊戲啟動到關閉為止。關閉爐石戰記後，上一個工作階段會一直顯示到下次啟動。儀表板開啟時顯示的就是這個期間。 |
| 「今天」 | 午夜以來的對戰 |
| 「本週」 | 週一 00:00 以來的對戰 |
| 「本賽季」 | 本月 1 日以來的對戰。爐石戰記的排名賽季以一個日曆月為期。 |
| 「最近 30 天」 | 最近 30 天的對戰，包含今天 |
| 「全部」 | 記錄中的所有對戰 |
| 「重新整理」 | 重新讀取記錄 |
| 「開啟資料夾」 | 在 Windows 檔案總管中開啟記錄檔所在的資料夾 |
| 「語言（Language）」 | 覆蓋層、儀表板和外掛程式選單項目的語言。預設為英文。變更會立即生效；儀表板會以新語言重新開啟。在其他語言中，標籤會保留英文單字，例如「語言（Language）」。 |
| 「覆蓋層位置」 | 覆蓋層的位置：「右側，設定按鈕上方」（預設）或「左側，你的頭像上方」（右側的 HDT 套牌清單不會被遮住）。覆蓋層會立即移動。 |
| 「事件進行中（顯示事件經驗值）」 | 在爐石戰記事件期間開啟：覆蓋層會顯示事件經驗值，新對戰也會記錄下來。 |
| 「旅店貴賓證（經驗值加成）」 | 如果你擁有目前資料片的旅店貴賓證，請開啟此項。加成是計算出來的，不是實測的：有貴賓證時，顯示的經驗值每場可能相差 1 點（請見 [FORMULA.md](../FORMULA.md#tavern-pass)）。 |
| 「等級」，附「−」、一個數字和「+」 | 你的獎勵軌跡等級。點擊「−」或「+」，或直接輸入數字。下方那一行會顯示加成和下一階段，例如「經驗值加成 10%，再升 2 級可達 15%」。加成為 10%，等級 20 起為 15%，等級 70 起為 20%（請見 [FORMULA.md](../FORMULA.md#tavern-pass)）。當你達到等級 20 或 70 時，請更新等級。 |
| 「在覆蓋層顯示傷害」 | 顯示或隱藏「總傷害：」和「英雄傷害：」這兩行。預設為開啟。 |
| 「啟動 HDT 時檢查更新」 | 開啟或關閉更新檢查。請見[隱私](#privacy)。 |

已結束的對戰會自動出現在已開啟的儀表板中。你不需要點擊「重新整理」。

選擇「本次工作階段」時，工具列下方會有一行說明這個工作階段，例如「自 週二 2026-11-10, 19:56 起的工作階段（進行中）」或「（已結束）」。工作階段可以跨過午夜。

<a id="tabs"></a>
### 分頁

**總覽**

| 資訊卡 | 意義 |
|---|---|
| 「經驗值」 | 這段期間獲得的經驗值 |
| 「經驗值時間」 | 計入經驗值的時間 |
| 「遊戲時間（含起手換牌）」 | 在對戰中的時間，包含選擇起手的手牌 |
| 「上線時間」 | 爐石戰記執行的時間。請見下方。 |
| 「對戰」 | 對戰場數，含勝場和敗場 |
| 「每小時經驗值」 | 每小時經驗值時間的經驗值 |
| 「每上線小時經驗值」 | 每小時上線時間的經驗值，因此包含選單和排隊 |
| 「勝率」 | 獲勝對戰所占的比例 |
| 「事件經驗值」 | 這段期間的事件經驗值；只有在事件期間有進行對戰時才會顯示 |

上線時間按爐石戰記工作階段計算：從爐石戰記啟動到最後一場對戰結束為止。爐石戰記執行期間，會一直計算到現在。只有在這段期間內至少有一場對戰的工作階段才會計入。

沒有實測速率的模式（例如英雄戰場）的對戰會不帶經驗值儲存。它們顯示在「對戰」中，並計入遊戲時間和上線時間，但不計入其他數值區塊、套牌表格和圖表。

**套牌**

每個套牌一行：對戰場數、勝率、經驗值、每小時經驗值和平均對戰長度。每小時經驗值最高的套牌排在最上面。

套牌名稱來自 HDT 本身的統計資料。HDT 沒有記錄到的對戰會顯示「沒有記錄套牌」。

**損失的經驗值**

| 資訊卡 | 意義 |
|---|---|
| 「閒置回合」 | 因閒置回合而損失的經驗值：沒有任何動作、也沒按「結束回合」就時間耗盡的回合，以及之後的對手回合 |
| 「不到 1 分鐘的對戰」 | 公式會為不到 60 秒的對戰算出、但遊戲不會給的經驗值 |
| 「對戰以外的時間」 | 花在對戰以外的上線時間（選單、排隊、休息），以你這段期間的每小時經驗值計算 |

**對戰**

這段期間的所有對戰，最新的在最前面：日期、開始、模式、結果、經驗值時間、總時間、經驗值、事件經驗值、閒置回合、套牌和對手職業。點擊欄位標題即可排序。

**圖表**

兩條曲線使用同一條時間軸。時間軸一律涵蓋整個期間，所以沒有對戰的小時或日子也會顯示：

| 期間 | 時間軸 |
|---|---|
| 「本次工作階段」 | 從工作階段開始到結束的每個小時，進行中時則到現在 |
| 「今天」 | 當天的 24 小時 |
| 「本週」 | 週一到週日 |
| 「本賽季」 | 本月的每一天 |
| 「最近 30 天」 | 最近 30 天，包含今天 |
| 「全部」 | 從記錄中第一場對戰起的每一天 |

| 曲線 | 意義 |
|---|---|
| 「獲得的經驗值」（金色） | 每個小時或每天開始的對戰所獲得的經驗值。沒有對戰的區段為 0。 |
| 「每小時經驗值」（藍色） | 每個小時或每天的速度：經驗值除以經驗值時間。只有有對戰的區段才有資料點。虛線是整個期間的平均值。 |

對戰會計入它開始的那個小時或那一天。

<a id="game-history-file"></a>
## 對戰記錄檔

每場結束的對戰都會加入一個 CSV 檔：

```
%APPDATA%\HearthstoneDeckTracker\XpTracker\hs_games.csv
```

這個檔案以逗號分隔欄位，並以句點作為小數點。時間為本地時間。

| 欄位 | 內容 |
|---|---|
| `Session` | 這個工作階段的爐石戰記記錄資料夾名稱，例如 `Hearthstone_2026_11_08_09_10_51` |
| `Start` | 第一個回合的開始時間，`yyyy-MM-ddTHH:mm:ss.fff` |
| `End` | 對戰的結束時間，格式相同 |
| `Mode` | 遊戲模式，例如 `Ranked` |
| `Format` | 賽制，例如 Standard 或 Wild；如果該模式沒有賽制則為空白 |
| `Result` | 例如 `Win` 或 `Loss` |
| `XpSeconds` | 計入經驗值的時間 |
| `PlaySeconds` | 從第一個回合到結束的時間，包含閒置回合 |
| `WithMulliganSeconds` | 包含選擇起手的手牌在內的時間 |
| `AfkTurns` | 自己的閒置回合數 |
| `Xp` | 外掛程式計算的經驗值；沒有實測速率的模式則為空白 |
| `Deck` | 來自 HDT 的套牌名稱 |
| `PlayerClass` | 你的職業 |
| `OpponentClass` | 對手的職業 |
| `EventXp` | 外掛程式計算的事件經驗值；非事件期間的對戰則為空白。沒有這個欄位的舊版本檔案仍然可以讀取，下一場對戰時會加入這個欄位。 |
| `XpBonus` | 對戰當時適用的旅店貴賓證經驗值加成百分比，例如 `15`；沒有貴賓證時為 `0`。沒有這個欄位的舊檔案會以 `0` 讀取。 |

`Xp` 欄位是外掛程式依經驗值時間計算出來的。遊戲本身不會記錄經驗值。儀表板開啟時，外掛程式會用目前的速率重新計算所有已儲存對戰的經驗值，所以修正後的速率也會修正舊的對戰。每場對戰都保留自己的 `XpBonus`，所以之後更改貴賓證或等級，不會改變舊的對戰。

從同一份記錄讀取兩次的對戰只會儲存一次。安裝新版外掛程式時，這個檔案會保留。

<a id="privacy"></a>
## 隱私

- 對戰記錄和設定都留在你的電腦上。外掛程式不會上傳任何東西。
- 唯一的網路請求是更新檢查。HDT 啟動時，外掛程式會向 GitHub 詢問一次是否有新版本。這個請求只會傳送外掛程式名稱和版本，例如 `HearthstoneXpTracker/0.1.0`。和任何網路請求一樣，GitHub 會看到你的 IP 位址。
- 要關閉更新檢查，請在儀表板中取消勾選「啟動 HDT 時檢查更新」。這項設定儲存在 `%APPDATA%\HearthstoneDeckTracker\XpTracker\settings.ini` 中。
