# 獲得更多經驗值

> 本文為機器輔助翻譯。如與[英文版](../FARMING.md)有出入，以英文版為準。歡迎指正：[提出 issue](https://github.com/critterbyte/hearthstone_xp_tracker/issues/new/choose)。

以公平方式提高每小時獎勵軌跡經驗值的技巧。這些技巧來自[經驗值公式](../FORMULA.md)。各項說法的標示方式與該頁相同：

- **實測**：由本專案測得。
- **根據 [n]**：來自本頁最後列出的資料來源。

外掛程式的儀表板會顯示你的經驗值流向哪裡。「損失的經驗值」分頁是很好的起點（請見 [USAGE.md](USAGE.md#tabs)）。

<a id="play-fair"></a>
## 公平遊戲

本頁談的是正常且有效率地遊玩。機器人、勝場交易、共用帳號，以及其他規避遊戲規則的方法都違反 Blizzard 的條款，可能導致你的帳號被停權。本頁不涵蓋這些內容。

<a id="choose-the-mode"></a>
## 選擇模式

| 模式 | 勝利 | 落敗 |
|---|---:|---:|
| 排名模式（標準與開放） | 470 經驗值/小時 | 336 經驗值/小時 |
| 休閒模式、旅店大亂鬥與競技場 | 336 經驗值/小時 | 240 經驗值/小時 |

- **實測**：排名模式給的經驗值是休閒模式、旅店大亂鬥和競技場的 1.40 倍。休閒模式的勝利與排名模式的落敗給的一樣多。
- **實測**：標準與開放給的一樣多。玩你喜歡或比較會贏的賽制就好。
- **實測**：勝利給的是落敗的 1.40 倍。你的勝率很重要，所以請使用你能贏的套牌。
- **根據 [1]**：英雄戰場每小時約給 300 經驗值。本專案未實測。

<a id="do-not-go-afk"></a>
## 不要閒置

- **實測**：如果你讓回合時間耗盡卻沒有任何動作，這個回合**和**對手的下一個回合都不會給經驗值。
- 如果你沒有牌可打，請點擊「**結束回合**」。沒有任何動作的回合，只要是你自己結束的，仍然會計入。
- 只要你打出至少一張牌、攻擊或使用英雄技能，即使計時器耗盡，這個回合也會計入。
- **實測**：當**對手**閒置時，你不會損失任何東西。對方的閒置回合對你來說完全計入。

<a id="mind-the-60-second-minimum"></a>
## 注意 60 秒下限

- **實測**：經驗值時間少於 60 秒的對戰**不會給任何經驗值**，連一點都沒有。這也包括對手提早投降的對戰。
- 如果你在開始後立刻投降，這場對戰什麼都不會給。

<a id="conceding"></a>
## 投降

- **實測**：投降不會有額外損失。你會依已遊玩的時間獲得落敗的速率。
- **實測**：落敗的對戰在進行期間仍會依落敗速率給經驗值，所以繼續打下去並不是浪費時間。
- **實測**：每開始一場新對戰，都會花掉沒有經驗值的時間：從一場對戰結束到下一場的第一個回合約 1:07（10 次的平均），再加上選擇起手的手牌約 35 秒。當下一場對戰可能更好時，投降才划算，例如你寧可去打一場能贏的對戰時。

<a id="game-length"></a>
## 對戰長度

- **實測**：每秒的經驗值是固定的。玩得比較慢，並不會提高每小時遊戲時間的經驗值；只會讓每場對戰的價值更高。
- 對戰越長，你花在排隊和選擇起手的手牌上的時間比例就越小。不過請不要故意拖延，這對你的對手很不禮貌。
- **根據 [2]**：每場對戰的經驗值時間上限約為 30 分鐘。超過的時間不會給任何經驗值。

<a id="quests-give-most-of-the-xp"></a>
## 大部分經驗值來自任務

- **根據 [3]**：「除了非常硬派的玩家之外，大部分經驗值都來自任務。」（原文：「Outside of the very hardcore player, majority of XP comes from quests.」）
- **根據 [4]**：每日任務給 900、1,000 或 1,500 經驗值。每週任務給 1,750 經驗值，而保證會有的排名模式每週任務（「在爐石戰記的排名模式中贏得 5 場對戰」）給 2,500 經驗值。
- **根據 [5]**：你每天可以更換一個每日任務和一個每週任務。被更換的任務進度會消失。
- 一個每日任務約等於兩到四小時的排名模式對戰。請挑選能在遊玩時順便完成任務的套牌和模式。

<a id="tavern-pass"></a>
## 旅店貴賓證

- **根據 [6]**：旅店貴賓證會立即給予 10% 經驗值加成，軌跡等級 20 時提高為 15%，等級 70 時提高為 20%，效果持續到該資料片結束。
- **根據 [7]**：加成適用於任何來源的經驗值。
- 未實測：加成是否剛好乘在對戰速率上。所有測量都是在沒有加成的情況下進行的。

<a id="track-size"></a>
## 軌跡規模

- **根據 [6]**：獎勵軌跡的等級 1 到 100 總共需要 155,200 經驗值。額外等級最高到等級 400，每級給 50 金幣。
- **根據 [7]**：每次推出新資料片時，軌跡都會重置。
