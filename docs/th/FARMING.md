# การได้ XP มากขึ้น

> แปลโดยใช้เครื่องช่วย หากเนื้อหาแตกต่างจาก[ฉบับภาษาอังกฤษ](../FARMING.md) ให้ยึดฉบับภาษาอังกฤษเป็นหลัก ยินดีรับการแก้ไข: [เปิด issue](https://github.com/critterbyte/hearthstone_xp_tracker/issues/new/choose)

เคล็ดลับแบบแฟร์ๆ เพื่อให้ได้ XP แทร็ครางวัลต่อชั่วโมงมากขึ้น เคล็ดลับเหล่านี้มาจาก[สูตร XP](../FORMULA.md) ข้อความต่างๆ มีการระบุที่มาแบบเดียวกับในหน้านั้น:

- **วัดแล้ว:** พบโดยโปรเจกต์นี้
- **ตาม [n]:** มาจากแหล่งอ้างอิงท้ายหน้านี้

แดชบอร์ดของปลั๊กอินแสดงให้เห็นว่า XP ของคุณไปอยู่ที่ไหน แท็บ "XP ที่เสียไป" เป็นจุดเริ่มต้นที่ดี (ดู [USAGE.md](USAGE.md#tabs))

<a id="play-fair"></a>
## เล่นอย่างแฟร์

หน้านี้พูดถึงการเล่นตามปกติอย่างมีประสิทธิภาพ บอท การแลกชนะ (win trading) การใช้บัญชีร่วมกัน และวิธีอื่นๆ ที่เลี่ยงกฎของเกม ล้วนละเมิดข้อกำหนดของ Blizzard และอาจทำให้บัญชีของคุณถูกแบน หน้านี้จึงไม่พูดถึงวิธีเหล่านั้น

<a id="choose-the-mode"></a>
## เลือกโหมด

| โหมด | ชนะ | แพ้ |
|---|---:|---:|
| จัดอันดับ (มาตรฐานและอิสระ) | 470 XP/ชม. | 336 XP/ชม. |
| ปกติ ท้าประลอง และลานประลอง | 336 XP/ชม. | 240 XP/ชม. |

- **วัดแล้ว:** จัดอันดับให้ XP มากกว่าปกติ ท้าประลอง และลานประลอง 1.40 เท่า การชนะในโหมดปกติให้ XP เท่ากับการแพ้ในโหมดจัดอันดับ
- **วัดแล้ว:** มาตรฐานและอิสระให้ XP เท่ากัน เล่นรูปแบบที่คุณชอบหรือชนะได้มากกว่า
- **วัดแล้ว:** การชนะให้ XP เป็น 1.40 เท่าของการแพ้ อัตราชนะของคุณจึงสำคัญ ให้ใช้เด็คที่คุณชนะได้
- **ตาม [1]:** Battlegrounds ให้ประมาณ 300 XP ต่อชั่วโมง โปรเจกต์นี้ยังไม่ได้วัด

<a id="do-not-go-afk"></a>
## อย่า AFK

- **วัดแล้ว:** หากคุณปล่อยให้เวลาเทิร์นหมดโดยไม่ได้ทำอะไรเลย เทิร์นนั้น **และ** เทิร์นถัดไปของคู่แข่งจะไม่ให้ XP
- หากคุณไม่มีอะไรจะเล่น ให้คลิก **"จบเทิร์น"** เทิร์นที่ไม่มีการกระทำใดๆ ยังนับอยู่ หากคุณจบเทิร์นเอง
- หากคุณเล่นการ์ดอย่างน้อยหนึ่งใบ โจมตี หรือใช้พลังฮีโร่ เทิร์นนั้นจะนับแม้ว่าเวลาจะหมด
- **วัดแล้ว:** เมื่อ **คู่แข่ง** AFK คุณไม่เสียอะไรเลย เทิร์นที่คู่แข่งปล่อยว่างจะนับให้คุณเต็มที่

<a id="mind-the-60-second-minimum"></a>
## ระวังขั้นต่ำ 60 วินาที

- **วัดแล้ว:** เกมที่มีเวลา XP น้อยกว่า 60 วินาทีจะ **ไม่ให้ XP เลย** แม้แต่นิดเดียว รวมถึงเกมที่คู่แข่งยอมแพ้เร็ว
- หากคุณยอมแพ้ทันทีหลังเริ่มเกม เกมนั้นจะไม่ให้อะไรเลย

<a id="conceding"></a>
## การยอมแพ้

- **วัดแล้ว:** การยอมแพ้ไม่มีค่าใช้จ่ายเพิ่ม คุณจะได้อัตราของการแพ้ตามเวลาที่เล่นไป
- **วัดแล้ว:** เกมที่กำลังแพ้ยังจ่ายอัตราของการแพ้ตลอดเวลาที่เล่น การเล่นต่อจึงไม่ใช่การเสียเวลา
- **วัดแล้ว:** ทุกเกมใหม่ใช้เวลาที่ไม่ได้ XP: ประมาณ 1:07 ตั้งแต่จบเกมหนึ่งจนถึงเทิร์นแรกของเกมถัดไป (ค่าเฉลี่ยจาก 10 ครั้ง) บวกกับช่วงเลือกการ์ดเริ่มเกมอีกประมาณ 35 วินาที การยอมแพ้คุ้มค่าเมื่อเกมถัดไปน่าจะดีกว่า เช่น เมื่อคุณอยากไปเล่นเกมที่มีโอกาสชนะมากกว่า

<a id="game-length"></a>
## ความยาวเกม

- **วัดแล้ว:** XP ต่อวินาทีคงที่ การเล่นช้าลงไม่ได้เพิ่ม XP ต่อชั่วโมงของเวลาในเกม แค่ทำให้แต่ละเกมมีค่ามากขึ้นเท่านั้น
- เกมที่ยาวกว่าทำให้สัดส่วนเวลาที่คุณใช้ไปกับการรอคิวและช่วงเลือกการ์ดเริ่มเกมน้อยลง อย่างไรก็ตาม โปรดอย่าถ่วงเวลาโดยเจตนา เพราะเป็นการเสียมารยาทต่อคู่แข่ง
- **ตาม [2]:** เวลา XP มีเพดานประมาณ 30 นาทีต่อเกม เวลาที่เกินจากนั้นไม่ให้อะไรเลย

<a id="quests-give-most-of-the-xp"></a>
## XP ส่วนใหญ่มาจากเควสต์

- **ตาม [3]:** "ยกเว้นผู้เล่นฮาร์ดคอร์จริงๆ แล้ว XP ส่วนใหญ่มาจากเควสต์" (ต้นฉบับ: "Outside of the very hardcore player, majority of XP comes from quests.")
- **ตาม [4]:** เควสต์ประจำวันให้ 900, 1,000 หรือ 1,500 XP เควสต์ประจำสัปดาห์ให้ 1,750 XP และเควสต์ประจำสัปดาห์ของโหมดจัดอันดับที่ได้รับแน่นอน ("ชนะ 5 เกมในโหมดจัดอันดับของ Hearthstone") ให้ 2,500 XP
- **ตาม [5]:** คุณเปลี่ยนเควสต์ประจำวันได้หนึ่งเควสต์และเควสต์ประจำสัปดาห์ได้หนึ่งเควสต์ในแต่ละวัน ความคืบหน้าของเควสต์ที่ถูกเปลี่ยนจะหายไป
- เควสต์ประจำวันหนึ่งเควสต์มีค่าประมาณสองถึงสี่ชั่วโมงของการเล่นจัดอันดับ เลือกเด็คและโหมดที่ทำเควสต์ให้สำเร็จไปพร้อมกับการเล่น

<a id="tavern-pass"></a>
## ทาเวิร์นพาส

- **ตาม [6]:** ทาเวิร์นพาสให้โบนัส XP 10% ทันที 15% ที่เลเวลแทร็ค 20 และ 20% ที่เลเวล 70 ไปจนจบส่วนเสริมนั้น
- **ตาม [7]:** โบนัสใช้กับ XP จากทุกแหล่ง
- ยังไม่ได้วัด: โบนัสคูณกับอัตราของเกมพอดีหรือไม่ การวัดทั้งหมดทำโดยไม่มีโบนัส

<a id="track-size"></a>
## ขนาดของแทร็ค

- **ตาม [6]:** เลเวล 1 ถึง 100 ของแทร็ครางวัลต้องใช้ XP รวม 155,200 เลเวลโบนัสไปได้ถึงเลเวล 400 และให้ 50 ทองต่อเลเวล
- **ตาม [7]:** แทร็คจะรีเซ็ตทุกครั้งที่มีส่วนเสริมใหม่
