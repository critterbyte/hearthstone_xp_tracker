# การใช้งาน

> แปลโดยใช้เครื่องช่วย หากเนื้อหาแตกต่างจาก[ฉบับภาษาอังกฤษ](../USAGE.md) ให้ยึดฉบับภาษาอังกฤษเป็นหลัก ยินดีรับการแก้ไข: [เปิด issue](https://github.com/critterbyte/hearthstone_xp_tracker/issues/new/choose)

ปลั๊กอินมีสามส่วน:

- **โอเวอร์เลย์** ในเกม
- หน้าต่าง **แดชบอร์ด**
- ไฟล์ **ประวัติเกม**

ข้อความในเครื่องหมายคำพูด เช่น "เวลา XP:" คือข้อความที่ปลั๊กอินแสดง

<a id="overlay"></a>
## โอเวอร์เลย์

โอเวอร์เลย์คือกล่องเล็กๆ ที่มุมขวาล่าง เหนือปุ่มการตั้งค่าของ Hearthstone (เฟืองที่มุมขวาล่าง) ในแดชบอร์ดคุณย้ายไปไว้ที่มุมซ้ายล่าง เหนือรูปของคุณ ("You" พร้อมแรงก์ของคุณ) แทนได้ ป้ายกำกับอยู่ทางซ้าย ค่าอยู่ทางขวาในแถบสีน้ำเงิน

โอเวอร์เลย์จะแสดงเฉพาะใน **จัดอันดับ ปกติ ท้าประลอง และลานประลอง** เท่านั้น โหมดอื่นยังไม่ได้วัด ปลั๊กอินจึงไม่แสดงอะไรในโหมดเหล่านั้น ท้าประลองที่เล่นกับคอมพิวเตอร์ (PvE เช่น เล่นกับเจ้าของโรงแรม) ไม่ให้ XP โอเวอร์เลย์จึงแสดง "+0" ในกรณีนั้น

<a id="during-a-game"></a>
### ระหว่างเกม

แถวต่างๆ จะปรากฏในเทิร์นแรก ระหว่างช่วงเลือกการ์ดเริ่มเกม โอเวอร์เลย์จะถูกซ่อนไว้

| แถว | ความหมาย |
|---|---|
| "เวลา XP:" | เวลาที่นับเป็น XP จนถึงตอนนี้ แสดงเป็นนาทีและวินาที |
| "ถ้าชนะ:" | XP ที่คุณจะได้หากชนะตอนนี้ |
| "ถ้าแพ้:" | XP ที่คุณจะได้หากแพ้หรือยอมแพ้ตอนนี้ |

เวลา XP อาจมีหมายเหตุ:

| หมายเหตุ | ความหมาย |
|---|---|
| "(หยุดชั่วคราว)" | คุณปล่อยให้เวลาเทิร์นหมดโดยไม่ได้ทำอะไรเลย เทิร์นนั้นและเทิร์นถัดไปของคู่แข่งจะไม่ถูกนับ เวลา XP จึงย้อนกลับและรออยู่ แล้วจะเดินต่อในเทิร์นถัดไปของคุณ |
| "(สูงสุด)" | เวลา XP ถึง 30 นาทีแล้ว เวลาที่มากกว่านี้จะไม่ให้ XP เพิ่ม |

ระหว่างที่มีกิจกรรมของ Hearthstone ให้เปิด "มีกิจกรรมอยู่ (แสดง XP กิจกรรม)" ในแดชบอร์ด โอเวอร์เลย์จะแสดงอีกหนึ่งแถว ทั้งแบบสดระหว่างเกมและในสรุปหลังจบเกม:

| แถว | ความหมาย |
|---|---|
| "XP กิจกรรม:" | XP กิจกรรมจนถึงตอนนี้ พร้อมคริสตัลสีแดง: 1 ต่อเวลา XP 1 นาที (ดู [FORMULA.md](../FORMULA.md#event-xp)) ไม่ขึ้นกับผลแพ้ชนะ |

ปิดตัวเลือกนี้เมื่อกิจกรรมจบ

เมื่อเปิด "ทาเวิร์นพาส (โบนัส XP)" ในแดชบอร์ด ค่า "ถ้าชนะ:" "ถ้าแพ้:" และ "ได้รับ:" จะรวมโบนัสจากพาสตามเลเวลแทร็ครางวัลของคุณ XP กิจกรรมไม่ได้รับโบนัส

สองแถวสุดท้ายแสดงความเสียหาย ทั้งแบบสดระหว่างเกมและในสรุปหลังจบเกม ปิดได้ด้วย "แสดงความเสียหายบนโอเวอร์เลย์" ในแดชบอร์ด

| แถว | ความหมาย |
|---|---|
| "ความเสียหายรวม:" | ความเสียหายทั้งหมดที่ฝั่งของคุณทำต่อฮีโร่และมินเนี่ยนของคู่แข่งจนถึงตอนนี้ ได้แก่ การโจมตีของคุณ การโจมตีของมินเนี่ยนของคุณ เวทมนตร์ อาวุธ พลังฮีโร่ และเอฟเฟกต์อื่นๆ การโจมตีแต่ละครั้งนับตามค่าที่เกมแสดง แม้จะมากกว่าพลังชีวิตของเป้าหมายหรือโดนเกราะก็ตาม ความเสียหายต่อฮีโร่หรือมินเนี่ยนของคุณเองไม่นับ และความเสียหายที่ไม่มีแหล่งที่มา เช่น ความเหนื่อยล้า ก็ไม่นับเช่นกัน การโจมตีที่โดนโล่ศักดิ์สิทธิ์นับเป็น 0 |
| "ความเสียหายต่อฮีโร่:" | ส่วนของ "ความเสียหายรวม:" ที่โดนฮีโร่ของคู่แข่ง รวมถึงส่วนที่เกราะดูดซับไว้ |

ความเสียหายจะถูกอ่านเมื่อเซิร์ฟเวอร์ยืนยันการกระทำ จึงอาจเพิ่มขึ้นก่อนแอนิเมชันบนกระดานเล็กน้อย

ขณะที่เวลา XP ต่ำกว่า 60 วินาที ค่า XP ทั้งสองจะแสดง "+0" เกมที่สั้นกว่าหนึ่งนาทีไม่ให้ XP ดูกฎได้ที่ [FORMULA.md](../FORMULA.md)

หากคุณเปิด HDT กลางเกม ปลั๊กอินจะยังอ่านเกมนั้นตั้งแต่ต้น

<a id="after-a-game"></a>
### หลังจบเกม

หลังจบเกม โอเวอร์เลย์จะแสดงสรุปไปจนถึงช่วงเลือกการ์ดเริ่มเกมของเกมถัดไป:

| แถว | ความหมาย |
|---|---|
| "เกมล่าสุด:" | ชนะ หรือ แพ้ |
| "เวลา XP:" | เวลาที่นับเป็น XP |
| "เวลารวม:" | เวลาทั้งเกม รวมช่วงเลือกการ์ดเริ่มเกม |
| "ได้รับ:" | XP ที่ได้จากเกมนั้น |

<a id="update-hint"></a>
### การแจ้งอัปเดต

เมื่อมีปลั๊กอินเวอร์ชันใหม่กว่า โอเวอร์เลย์จะแสดงอีกหนึ่งแถวขณะที่ไม่มีเกมกำลังเล่นอยู่:

| แถว | ความหมาย |
|---|---|
| "มีอัปเดต:" | หมายเลขเวอร์ชันใหม่ เช่น 0.2.0 |

แดชบอร์ดจะแสดงลิงก์ไปยังหน้าดาวน์โหลด ดูวิธีอัปเดตได้ที่ [INSTALL.md](INSTALL.md#update)

<a id="dashboard"></a>
## แดชบอร์ด

หน้าต่างแดชบอร์ดชื่อ "HS XP Tracker" เปิดได้ใน HDT ด้วยวิธีใดวิธีหนึ่งต่อไปนี้:

- เมนู *Plugins* → "แดชบอร์ด XP"
- *Settings* (ไอคอนเฟืองทางขวาของแถบด้านบน) *→ Tracker → Plugins* → ปุ่ม "แดชบอร์ด XP" ของปลั๊กอิน

### แถบเครื่องมือ

| ตัวควบคุม | ความหมาย |

| "ภาษา (Language)" | ภาษาของโอเวอร์เลย์ แดชบอร์ด และรายการเมนูของปลั๊กอิน ค่าเริ่มต้นคือภาษาอังกฤษ การเปลี่ยนแปลงมีผลทันที และแดชบอร์ดจะเปิดใหม่ในภาษาใหม่ ในภาษาอื่น ป้ายชื่อจะมีคำภาษาอังกฤษกำกับไว้ เช่น "ภาษา (Language)" |

สำหรับ "เซสชัน" จะมีบรรทัดใต้แถบเครื่องมือบอกชื่อเซสชัน เช่น "เซสชันตั้งแต่ อ. 2026-11-10, 19:56 (กำลังดำเนินอยู่)" หรือ "(จบแล้ว)" เซสชันหนึ่งอาจต่อเนื่องข้ามเที่ยงคืนได้

### แท็บ

**ภาพรวม**

| ช่องข้อมูล | ความหมาย |
|---|---|
| "XP" | XP ที่ได้รับในช่วงเวลานั้น |
| "เวลา XP" | เวลาที่นับเป็น XP |
| "เวลาเล่นรวมการ์ดเริ่มเกม" | เวลาในเกม รวมช่วงเลือกการ์ดเริ่มเกม |
| "เวลาออนไลน์" | เวลาที่ Hearthstone เปิดอยู่ ดูด้านล่าง |
| "เกม" | จำนวนเกม พร้อมจำนวนที่ชนะและแพ้ |
| "XP ต่อชั่วโมง" | XP ต่อหนึ่งชั่วโมงของเวลา XP |
| "XP ต่อชั่วโมงออนไลน์" | XP ต่อหนึ่งชั่วโมงของเวลาออนไลน์ ซึ่งรวมเมนูและการรอคิวด้วย |
| "อัตราชนะ" | สัดส่วนของเกมที่ชนะ |
| "XP กิจกรรม" | XP กิจกรรมของช่วงเวลานั้น จะแสดงเฉพาะเมื่อมีเกมที่เล่นระหว่างกิจกรรม |

เวลาออนไลน์นับตามเซสชันของ Hearthstone: ตั้งแต่เปิด Hearthstone จนถึงจบเกมสุดท้าย ขณะที่ Hearthstone ยังเปิดอยู่ จะนับจนถึงตอนนี้ เฉพาะเซสชันที่มีอย่างน้อยหนึ่งเกมในช่วงเวลานั้นเท่านั้นที่นับ

เกมในโหมดที่ยังไม่ได้วัดอัตรา เช่น Battlegrounds จะถูกบันทึกโดยไม่มี XP เกมเหล่านี้แสดงใน"เกม" และนับรวมในเวลาเล่นและเวลาออนไลน์ แต่ไม่นับในไทล์อื่น ตารางเด็ค และกราฟ

**เด็ค**

เด็คละหนึ่งแถว: จำนวนเกม อัตราชนะ XP XP ต่อชั่วโมง และความยาวเกมเฉลี่ย เด็คที่มี XP ต่อชั่วโมงสูงสุดจะอยู่บนสุด

ชื่อเด็คมาจากสถิติของ HDT เอง เกมที่ HDT ไม่ได้บันทึกจะแสดง "ไม่มีบันทึกเด็ค"

**XP ที่เสียไป**

| ช่องข้อมูล | ความหมาย |
|---|---|
| "เทิร์น AFK" | XP ที่คุณเสียไปเพราะเทิร์น AFK: เทิร์นที่ไม่มีการกระทำใดๆ และหมดเวลาโดยไม่ได้กด "จบเทิร์น" รวมถึงเทิร์นของคู่แข่งที่ตามมา |
| "เกมที่สั้นกว่า 1 นาที" | XP ที่สูตรจะให้สำหรับเกมที่สั้นกว่า 60 วินาที ซึ่งเกมไม่จ่ายให้ |
| "เวลานอกเกม" | เวลาออนไลน์ที่อยู่นอกเกม (เมนู คิว พัก) คิดมูลค่าตาม XP ต่อชั่วโมงของคุณในช่วงเวลานั้น |

**เกม**

เกมทั้งหมดในช่วงเวลานั้น เรียงจากใหม่สุด: วันที่ เวลาเริ่ม โหมด ผลลัพธ์ เวลา XP เวลารวม XP XP กิจกรรม เทิร์น AFK เด็ค และคลาสของคู่แข่ง คลิกหัวคอลัมน์เพื่อเรียงลำดับ

**กราฟ**

เส้นกราฟสองเส้นบนแกนเวลาเดียวกัน แกนเวลาครอบคลุมทั้งช่วงเวลาเสมอ ชั่วโมงหรือวันที่ไม่มีเกมจึงยังมองเห็นได้:

| ช่วงเวลา | แกนเวลา |
|---|---|
| "เซสชัน" | ทุกชั่วโมงตั้งแต่เริ่มเซสชันจนจบ หรือจนถึงตอนนี้หากยังดำเนินอยู่ |
| "วันนี้" | 24 ชั่วโมงของวัน |
| "สัปดาห์นี้" | วันจันทร์ถึงวันอาทิตย์ |
| "ซีซันนี้" | ทุกวันของเดือน |
| "30 วันล่าสุด" | 30 วันล่าสุด รวมวันนี้ |
| "ทั้งหมด" | ทุกวันตั้งแต่เกมแรกในประวัติ |

| เส้นกราฟ | ความหมาย |
|---|---|
| "XP ที่ได้รับ" (สีทอง) | XP ของเกมที่เริ่มในแต่ละชั่วโมงหรือแต่ละวัน ช่วงที่ไม่มีเกมจะเป็น 0 |
| "XP ต่อชั่วโมง" (สีน้ำเงิน) | ความเร็วในแต่ละชั่วโมงหรือแต่ละวัน: XP หารด้วยเวลา XP เฉพาะช่วงที่มีเกมเท่านั้นที่มีจุด เส้นประคือค่าเฉลี่ยของทั้งช่วงเวลา |

เกมจะนับในชั่วโมงหรือวันที่เกมนั้นเริ่ม

<a id="game-history-file"></a>
## ไฟล์ประวัติเกม

ทุกเกมที่จบแล้วจะถูกเพิ่มลงในไฟล์ CSV:

```
%APPDATA%\HearthstoneDeckTracker\XpTracker\hs_games.csv
```

ไฟล์นี้ใช้เครื่องหมายจุลภาคคั่นระหว่างฟิลด์ และใช้จุดเป็นจุดทศนิยม เวลาเป็นเวลาท้องถิ่น

| คอลัมน์ | เนื้อหา |
|---|---|
| `Session` | ชื่อโฟลเดอร์ล็อกของ Hearthstone สำหรับเซสชันนั้น เช่น `Hearthstone_2026_11_08_09_10_51` |
| `Start` | เวลาเริ่มของเทิร์นแรก `yyyy-MM-ddTHH:mm:ss.fff` |
| `End` | เวลาจบเกม รูปแบบเดียวกัน |
| `Mode` | โหมดเกม เช่น `Ranked` |
| `Format` | รูปแบบการเล่น เช่น Standard หรือ Wild ว่างไว้หากโหมดนั้นไม่มี |
| `Result` | เช่น `Win` หรือ `Loss` |
| `XpSeconds` | เวลาที่นับเป็น XP |
| `PlaySeconds` | เวลาตั้งแต่เทิร์นแรกจนจบเกม รวมเทิร์น AFK |
| `WithMulliganSeconds` | เวลารวมช่วงเลือกการ์ดเริ่มเกม |
| `AfkTurns` | จำนวนเทิร์น AFK ของคุณเอง |
| `Xp` | XP ที่ปลั๊กอินคำนวณ ว่างไว้สำหรับโหมดที่ยังไม่มีอัตราที่วัดแล้ว |
| `Deck` | ชื่อเด็คจาก HDT |
| `PlayerClass` | คลาสของคุณ |
| `OpponentClass` | คลาสของคู่แข่ง |
| `EventXp` | XP กิจกรรมที่ปลั๊กอินคำนวณ ว่างไว้สำหรับเกมนอกช่วงกิจกรรม ไฟล์จากเวอร์ชันเก่าที่ไม่มีคอลัมน์นี้ยังอ่านได้ และคอลัมน์จะถูกเพิ่มเมื่อมีเกมถัดไป |
| `XpBonus` | โบนัส XP จากทาเวิร์นพาสเป็นเปอร์เซ็นต์ที่ใช้อยู่ตอนเล่นเกมนั้น เช่น `15` และเป็น `0` หากไม่มีพาส ไฟล์เก่าที่ไม่มีคอลัมน์นี้จะถูกอ่านเป็น `0` |

คอลัมน์ `Xp` คำนวณโดยปลั๊กอินจากเวลา XP ตัวเกมเองไม่ได้บันทึก XP ลงล็อก เมื่อเปิดแดชบอร์ด ปลั๊กอินจะคำนวณ XP ของทุกเกมที่บันทึกไว้ใหม่ด้วยอัตราปัจจุบัน ดังนั้นการแก้ไขอัตราจะแก้เกมเก่าด้วย แต่ละเกมเก็บ `XpBonus` ของตัวเองไว้ การเปลี่ยนพาสหรือเลเวลภายหลังจึงไม่เปลี่ยนเกมเก่า

เกมที่ถูกอ่านสองครั้งจากล็อกเดียวกันจะถูกบันทึกเพียงครั้งเดียว การติดตั้งปลั๊กอินเวอร์ชันใหม่จะเก็บไฟล์นี้ไว้

<a id="privacy"></a>
## ความเป็นส่วนตัว

- ประวัติเกมและการตั้งค่าอยู่ในคอมพิวเตอร์ของคุณ ปลั๊กอินไม่อัปโหลดอะไรเลย
- คำขอเครือข่ายเพียงอย่างเดียวคือการตรวจหาอัปเดต เมื่อ HDT เริ่มทำงาน ปลั๊กอินจะถาม GitHub หนึ่งครั้งว่ามีรุ่นใหม่กว่าหรือไม่ คำขอนี้ส่งเพียงชื่อและเวอร์ชันของปลั๊กอิน เช่น `HearthstoneXpTracker/0.1.0` เช่นเดียวกับคำขอเว็บทั่วไป GitHub จะเห็นที่อยู่ IP ของคุณ
- หากต้องการปิดการตรวจหาอัปเดต ให้ยกเลิกการเลือก "ตรวจหาอัปเดตเมื่อเริ่ม HDT" ในแดชบอร์ด การตั้งค่านี้เก็บอยู่ใน `%APPDATA%\HearthstoneDeckTracker\XpTracker\settings.ini`
