# การติดตั้ง

> แปลโดยใช้เครื่องช่วย หากเนื้อหาแตกต่างจาก[ฉบับภาษาอังกฤษ](../INSTALL.md) ให้ยึดฉบับภาษาอังกฤษเป็นหลัก ยินดีรับการแก้ไข: [เปิด issue](https://github.com/critterbyte/hearthstone_xp_tracker/issues/new/choose)

<a id="requirements"></a>
## สิ่งที่ต้องมี

- Windows 10 หรือ 11 ตัวติดตามต้องใช้ .NET Framework 4.7.2 ซึ่งมีอยู่แล้วในทั้งสองเวอร์ชัน
- Hearthstone

ตัวติดตามจะอ่านไฟล์ `Power.log` ของ Hearthstone โดย Hearthstone จะเขียนล็อกนี้ก็ต่อเมื่อเปิดใช้ไว้ในไฟล์การตั้งค่าของเกมเอง คือ `%LOCALAPPDATA%\Blizzard\Hearthstone\log.config` ตัวติดตามจะเปิดใช้ล็อกนี้ให้เมื่อเริ่มทำงานครั้งแรก โดยเพิ่มส่วน `[Power]` และไม่เปลี่ยนแปลงสิ่งอื่นในไฟล์ ก่อนเปลี่ยนแปลง ตัวติดตามจะเก็บสำเนาของไฟล์เดิมไว้เป็น `log.config.bak`

<a id="install"></a>
## ติดตั้ง

1. ดาวน์โหลดไฟล์ ZIP ของรุ่นล่าสุดจาก[หน้า Releases](https://github.com/critterbyte/hearthstone_xp_tracker/releases) เช่น `HearthstoneXpTracker-0.2.0.zip`
2. คลิกขวาที่ไฟล์ ZIP เลือก *คุณสมบัติ* (*Properties*) แล้วเลือก *เลิกบล็อก* (*Unblock*) หากมีตัวเลือกนี้
3. แตกไฟล์ ZIP ลงในโฟลเดอร์ที่คุณต้องการ เช่น *เอกสาร* (*Documents*) จะได้โฟลเดอร์ `HearthstoneXpTracker` ที่มีไฟล์เหล่านี้:
   - `HearthstoneXpTracker.exe`: ตัวติดตาม
   - `HearthstoneXpTracker.exe.config`, `XpTracker.Core.dll`, `LiveCharts.dll`, `LiveCharts.Wpf.dll` และ `Newtonsoft.Json.dll`: ไฟล์ที่ตัวติดตามต้องใช้
   - `INSTALL.txt`, `LICENSE.txt` และ `THIRD-PARTY-NOTICES.txt`

   เลือกโฟลเดอร์ที่คุณเขียนไฟล์ได้ หากเป็น *Program Files* การอัปเดตทุกครั้งจะต้องใช้สิทธิ์ผู้ดูแลระบบ
4. เปิด `HearthstoneXpTracker.exe` หาก Windows แสดง "Windows ปกป้องพีซีของคุณแล้ว" (*Windows protected your PC*) ให้เลือก *ข้อมูลเพิ่มเติม* (*More info*) แล้วเลือก *เรียกใช้ต่อไป* (*Run anyway*) ตัวติดตามยังไม่มีลายเซ็นดิจิทัล Windows จึงยังไม่รู้จัก
5. แดชบอร์ดจะเปิดขึ้น และไอคอน "XP" สีทองจะปรากฏในพื้นที่แจ้งเตือน (*notification area*) ที่มุมขวาล่างของแถบงาน ไอคอนอาจซ่อนอยู่หลังลูกศรเล็กๆ (^)

หาก Hearthstone เปิดอยู่แล้วตอนที่เริ่มตัวติดตามครั้งแรก ให้รีสตาร์ท Hearthstone หนึ่งครั้ง เพราะ Hearthstone จะอ่าน `log.config` เฉพาะตอนเริ่มเกมเท่านั้น

โอเวอร์เลย์จะปรากฏในเทิร์นแรกของเกมถัดไปของคุณ ดูว่าโอเวอร์เลย์แสดงอะไรบ้างได้ที่ [USAGE.md](USAGE.md)

ไฟล์ทั้งหมดต้องอยู่รวมกันในโฟลเดอร์เดียว เมื่อเริ่มครั้งแรก แถบด้านบนของแดชบอร์ดจะถามหนึ่งครั้งว่าจะเพิ่มตัวติดตามลงในเมนูเริ่มหรือไม่ หากต้องการให้ตัวติดตามเริ่มอัตโนมัติเมื่อคุณลงชื่อเข้าใช้ Windows ให้ทำเครื่องหมายที่ "เริ่มพร้อม Windows" ในแดชบอร์ด หากภายหลังคุณย้ายโฟลเดอร์ ให้เปิดตัวติดตามจากตำแหน่งใหม่หนึ่งครั้ง แล้วตัวติดตามจะอัปเดตทางลัดในเมนูเริ่มและรายการเริ่มอัตโนมัติให้

แต่ละรุ่นจะระบุค่า checksum SHA-256 ของไฟล์ ZIP ไว้ หากต้องการตรวจสอบไฟล์ที่ดาวน์โหลด ให้รัน `Get-FileHash HearthstoneXpTracker-0.2.0.zip` ใน PowerShell แล้วเปรียบเทียบผลลัพธ์

<a id="coming-from-the-hdt-plugin"></a>
## ย้ายมาจากปลั๊กอิน HDT

จนถึงเวอร์ชัน 0.1.2 ตัวติดตามเป็นปลั๊กอินของ HDT แต่ HDT จะหยุดรองรับปลั๊กอินในวันที่ 30 พฤศจิกายน 2026 ตัวติดตามจึงกลายเป็นโปรแกรมแยกของตัวเอง โดยมีโอเวอร์เลย์และแดชบอร์ดเหมือนเดิม

- **ข้อมูลของคุณย้ายมาด้วย** ทุกครั้งที่เริ่มทำงาน ตัวติดตามจะเพิ่มเกมจากประวัติของปลั๊กอิน (`%APPDATA%\HearthstoneDeckTracker\XpTracker\hs_games.csv`) ที่ตัวเองยังไม่มี และหากตัวติดตามยังไม่มีการตั้งค่าของตัวเอง ก็จะรับการตั้งค่าของปลั๊กอินมาใช้หนึ่งครั้ง ไฟล์ของปลั๊กอินจะถูกอ่านเท่านั้น และจะไม่ถูกเปลี่ยนแปลงเลย
- **ปิดใช้งานปลั๊กอิน** ใน HDT ให้เปิด *Settings* (ไอคอนเฟืองทางขวาของแถบด้านบน) *→ Tracker → Plugins* แล้วปิดใช้งาน **Hearthstone XP Tracker** มิฉะนั้นจะมีโอเวอร์เลย์สองอันที่แสดงตัวเลขเดียวกัน คุณยังลบโฟลเดอร์ `%APPDATA%\HearthstoneDeckTracker\Plugins\HearthstoneXpTracker` ได้ด้วย
- **ยังไม่มีชื่อเด็คในตอนนี้** ชื่อเด็คเคยได้มาจาก HDT ดังนั้นแท็บ *เด็ค* และคอลัมน์เด็คจึงถูกนำออกไปก่อน เกมเก่ายังคงมีชื่อเด็คอยู่ในไฟล์ประวัติ

<a id="update"></a>
## อัปเดต

เมื่อมีเวอร์ชันใหม่กว่า ตัวติดตามจะแจ้งให้คุณทราบ (ดู [USAGE.md](USAGE.md#update-hint)) วิธีอัปเดต:

1. ดาวน์โหลดไฟล์ ZIP ของรุ่นใหม่และเลิกบล็อกไฟล์ (ดูด้านบน)
2. ปิดตัวติดตาม: คลิกขวาที่ไอคอน "XP" สีทอง แล้วเลือก "ออก"
3. แตกไฟล์ ZIP ลงในโฟลเดอร์เดิมอีกครั้ง และแทนที่ไฟล์เดิม
4. เปิด `HearthstoneXpTracker.exe`

ประวัติเกมและการตั้งค่าของคุณจะยังอยู่ เพราะถูกเก็บไว้ในโฟลเดอร์อื่น (ดูด้านล่าง)

หากต้องการกลับไปใช้เวอร์ชันเก่า ให้ทำแบบเดียวกันด้วยไฟล์ ZIP ของเวอร์ชันนั้น

<a id="uninstall"></a>
## ถอนการติดตั้ง

1. ในแดชบอร์ด ให้เอาเครื่องหมายออกจาก "เริ่มพร้อม Windows" และ "ทางลัดในเมนูเริ่ม"
2. ปิดตัวติดตาม: คลิกขวาที่ไอคอน "XP" สีทอง แล้วเลือก "ออก"
3. ลบโฟลเดอร์ `HearthstoneXpTracker` ที่คุณแตกไฟล์ไว้

ตัวติดตามเก็บข้อมูลของคุณไว้ใน `%APPDATA%\HearthstoneXpTracker`:

| ไฟล์ | เนื้อหา |
|---|---|
| `hs_games.csv` | ประวัติเกม |
| `settings.ini` | การตั้งค่า |
| `xptracker.log` | ข้อผิดพลาดที่ไม่คาดคิด (ถ้ามี) |

หากไม่ต้องการเก็บข้อมูลไว้ ให้ลบโฟลเดอร์นี้ด้วย

ส่วน `[Power]` จะยังคงอยู่ใน `log.config` เพราะโปรแกรมอื่นก็อาจใช้ส่วนนี้เช่นกัน ส่วนนี้มีไว้เพียงให้ Hearthstone เขียนล็อกเท่านั้น หากต้องการคืนไฟล์ให้เป็นเหมือนก่อนหน้านี้ ให้แทนที่ `log.config` ด้วย `log.config.bak`

<a id="troubleshooting"></a>
## การแก้ไขปัญหา

**Windows แสดง "Windows ปกป้องพีซีของคุณแล้ว" (*Windows protected your PC*)**

- เลือก *ข้อมูลเพิ่มเติม* (*More info*) แล้วเลือก *เรียกใช้ต่อไป* (*Run anyway*) Windows จะแสดงข้อความนี้กับโปรแกรมที่ยังไม่รู้จัก ตัวติดตามเป็นโอเพนซอร์ส คุณอ่านโค้ดได้บน GitHub และตรวจสอบค่า checksum SHA-256 ของไฟล์ ZIP ได้

**ไม่มีอะไรเกิดขึ้นเมื่อเปิดตัวติดตาม**

- ตัวติดตามอาจทำงานอยู่แล้ว การเปิดอีกครั้งจะเปิดแดชบอร์ดของตัวติดตามที่ทำงานอยู่ ให้มองหาไอคอน "XP" สีทองในพื้นที่แจ้งเตือน รวมถึงหลังลูกศรเล็กๆ (^) ด้วย
- ตรวจสอบว่าไฟล์ทั้งหมดจาก ZIP อยู่ในโฟลเดอร์เดียวกัน และได้เลิกบล็อกไฟล์ ZIP แล้ว (ดู[ติดตั้ง](#install))

**โอเวอร์เลย์ไม่ปรากฏ**

- โอเวอร์เลย์จะแสดงเฉพาะในโหมดจัดอันดับ ปกติ ท้าประลอง และลานประลองเท่านั้น โหมดอื่นยังไม่ได้วัด
- ระหว่างช่วงเลือกการ์ดเริ่มเกม โอเวอร์เลย์จะถูกซ่อนไว้ และจะปรากฏในเทิร์นแรก
- โอเวอร์เลย์จะแสดงเฉพาะขณะที่ Hearthstone เป็นหน้าต่างที่ใช้งานอยู่ ให้คลิกในเกมหนึ่งครั้ง
- ดูบรรทัดสถานะในแดชบอร์ด ใต้ปุ่มช่วงเวลา บรรทัดนั้นควรแสดง "บันทึกเกม (Power.log): เปิด" หากบรรทัดนั้นขอให้รีสตาร์ท Hearthstone ก็ให้ทำตาม

**แดชบอร์ดแจ้งว่าไม่สามารถเปิดบันทึกเกมได้**

- ตัวติดตามเขียนไฟล์ `%LOCALAPPDATA%\Blizzard\Hearthstone\log.config` ไม่ได้ ให้ปิด Hearthstone เปิดไฟล์นั้นด้วย *แผ่นจดบันทึก* (*Notepad*) (สร้างไฟล์ใหม่หากยังไม่มี) เพิ่มบรรทัดเหล่านี้ไว้ท้ายไฟล์ แล้วบันทึก:

  ```ini
  [Power]
  LogLevel=1
  FilePrinting=True
  ConsolePrinting=False
  ScreenPrinting=False
  Verbose=True
  ```

**มีปัญหาอื่น**

โปรด[เปิด issue](https://github.com/critterbyte/hearthstone_xp_tracker/issues/new/choose) และระบุเวอร์ชันของตัวติดตาม (แดชบอร์ดแสดงไว้ที่มุมขวาบน) เวอร์ชัน Windows ของคุณ และสิ่งที่คุณคาดว่าจะเห็น หากมีไฟล์ `%APPDATA%\HearthstoneXpTracker\xptracker.log` บรรทัดท้ายๆ ของไฟล์นั้นก็ช่วยได้เช่นกัน
