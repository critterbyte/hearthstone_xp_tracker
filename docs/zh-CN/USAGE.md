# 使用方法

> 本文为机器辅助翻译。如与[英文版](../USAGE.md)有出入，以英文版为准。欢迎指正：[提交 issue](https://github.com/critterbyte/hearthstone_xp_tracker/issues/new/choose)。

追踪器在后台运行，任务栏右下角的通知区域（*notification area*）中会有一个金色的“XP”图标。它由三部分组成：

- 游戏中的**叠加层**
- **面板**窗口
- **对局记录**文件

引号中的文字，例如“经验值时间：”，就是追踪器显示的文字。

<a id="overlay"></a>
## 叠加层

叠加层是一个小方框，位于右下角炉石传说设置按钮（右下角的齿轮）上方。你也可以在面板中把它移到左下角你的头像（显示你的段位的“You”）上方。标签在左边，数值在右边的蓝色条中。

只有当炉石传说是活动窗口时，才会显示叠加层。它从不抢占焦点，每次点击都会穿过它传到游戏中。

叠加层只会在**排名模式、休闲模式、乱斗模式和竞技模式**中显示。其他模式尚未实测，所以追踪器在这些模式中不显示任何内容。对战电脑的乱斗（PvE，例如对战旅店老板）不给经验值，所以叠加层在那里会显示“+0”。

<a id="during-a-game"></a>
### 对局中

这些行会在第一个回合出现。在选择起始手牌时，叠加层会隐藏。

| 行 | 含义 |
|---|---|
| “经验值时间：” | 到目前为止计入经验值的时间，以分和秒表示 |
| “获胜时：” | 如果你现在获胜，会得到的经验值 |
| “失败时：” | 如果你现在失败或认输，会得到的经验值 |

经验值时间可能带有备注：

| 备注 | 含义 |
|---|---|
| “（暂停）” | 你让回合时间耗尽，却没有进行任何操作。这个回合和对手的下一个回合都不计入，所以经验值时间会往回跳并等待。它会在你的下一个回合重新开始计时。 |
| “（上限）” | 经验值时间已达到 30 分钟。更多时间不会再给更多经验值。 |

在炉石传说活动期间，请在面板中开启“活动进行中（显示活动经验值）”。叠加层就会多显示一行，在对局中实时显示，也会显示在对局结束后的摘要中：

| 行 | 含义 |
|---|---|
| “活动经验值：” | 到目前为止的活动经验值，旁边有红色水晶：每分钟经验值时间 1 点（请参阅 [FORMULA.md](../FORMULA.md#event-xp)）。它与胜负无关。 |

活动结束时，请将它关闭。

在面板中开启“炉石通行证（经验值加成）”后，“获胜时：”、“失败时：”和“获得：”都会包含按你的奖励路线等级计算的通行证加成。活动经验值没有加成。

最后两行显示伤害，在对局中实时显示，也会显示在对局结束后的摘要中。你可以在面板中用“在叠加层显示伤害”将它们关闭。

| 行 | 含义 |
|---|---|
| “总伤害：” | 到目前为止你这一方对对手英雄和随从造成的所有伤害：你的攻击、你的随从的攻击、法术、武器、英雄技能和其他效果。每次命中都按游戏显示的数值计算，即使超过目标的生命值或打在护甲上也一样。对你自己的英雄或随从造成的伤害不计入，没有来源的伤害（例如疲劳）也不计入。命中圣盾的伤害为 0。 |
| “英雄伤害：” | “总伤害：”中命中对手英雄的部分，包括被护甲吸收的部分 |

伤害会在服务器确认操作时读取，所以可能会比场上的动画早一点增加。

经验值时间低于 60 秒时，两个经验值数值都会显示“+0”。不到一分钟的对局不给经验值。规则请参阅 [FORMULA.md](../FORMULA.md)。

如果你在对局中途启动追踪器，它仍会从开头读取这局对局。

<a id="after-a-game"></a>
### 对局后

对局结束后，叠加层会显示摘要，直到你下一局选择起始手牌时为止：

| 行 | 含义 |
|---|---|
| “上一局：” | 胜利或失败 |
| “经验值时间：” | 计入经验值的时间 |
| “总时间：” | 整局对局的时间，包括选择起始手牌 |
| “获得：” | 这局对局给的经验值 |

<a id="update-hint"></a>
### 更新提示

追踪器有新版本时，叠加层会在没有对局进行时多显示一行：

| 行 | 含义 |
|---|---|
| “有可用更新：” | 新版本的版本号，例如 0.2.0 |

面板会显示下载页面的链接。更新方法请参阅 [INSTALL.md](INSTALL.md#update)。

<a id="dashboard"></a>
## 面板

面板窗口的名称是“HS XP Tracker”。追踪器启动时会打开它。要再次打开它：

- 单击通知区域中的金色“XP”图标，或
- 右键单击该图标，选择“经验值面板”，或
- 再次启动 `HearthstoneXpTracker.exe`。

关闭面板后，追踪器和叠加层仍会继续运行。要退出追踪器，请右键单击该图标，选择“退出”。

<a id="toolbar"></a>
### 工具栏

| 控件 | 含义 |
|---|---|
| “本次会话” | 当前炉石传说会话的对局，从游戏启动到关闭为止。关闭炉石传说后，上一个会话会一直显示到下次启动。面板打开时显示的就是这个时段。 |
| “今天” | 午夜以来的对局 |
| “本周” | 周一 00:00 以来的对局 |
| “本赛季” | 本月 1 日以来的对局。炉石传说的排名赛季以一个自然月为期。 |
| “最近 30 天” | 最近 30 天的对局，包括今天 |
| “全部” | 记录中的所有对局 |
| “刷新” | 重新读取记录 |
| “打开数据文件夹” | 在 Windows 文件资源管理器中打开记录文件所在的文件夹 |
| “语言（Language）” | 叠加层、面板和图标菜单的语言。默认为英语。更改会立即生效；面板会以新语言重新打开。在其他语言中，标签会保留英文单词，例如“语言（Language）”。 |
| “叠加层位置” | 叠加层的位置：“右侧，设置按钮上方”（默认）或“左侧，你的头像上方”（右侧会保持空出，例如留给其他叠加层）。叠加层会立即移动。 |
| “活动进行中（显示活动经验值）” | 在炉石传说活动期间开启：叠加层会显示活动经验值，新对局也会记录下来。追踪器无法得知活动何时进行，所以此项默认关闭；关闭时，下方会有一行简短的提示提醒你。 |
| “炉石通行证（经验值加成）” | 如果你拥有当前扩展包的炉石通行证，请开启此项。加成是计算得出的，不是实测的：有通行证时，显示的经验值每局可能相差 1 点（请参阅 [FORMULA.md](../FORMULA.md#tavern-pass)）。 |
| “等级”，带“−”、一个数字和“+” | 你的奖励路线等级。点击“−”或“+”，或直接输入数字。下方那一行会显示加成和下一档，例如“经验值加成 10%，再升 2 级可达 15%”。加成为 10%，20 级起为 15%，70 级起为 20%（请参阅 [FORMULA.md](../FORMULA.md#tavern-pass)）。当你达到 20 级或 70 级时，请更新等级。 |
| “在叠加层显示伤害” | 显示或隐藏“总伤害：”和“英雄伤害：”这两行。默认开启。 |
| “启动追踪器时检查更新” | 开启或关闭更新检查。请参阅[隐私](#privacy)。 |
| “随 Windows 启动” | 登录 Windows 时启动追踪器。此时它只出现在通知区域，点击图标即可打开面板。默认关闭。也可以在任务管理器的 *启动应用*（*Startup apps*）中关闭。 |
| “开始菜单快捷方式” | 将“Hearthstone XP Tracker”添加到“开始”菜单或从中删除。首次启动时，面板顶部的提示栏会询问一次。 |

结束的对局会自动出现在已打开的面板中。你不需要点击“刷新”。

选择“本次会话”时，工具栏下方会有一行说明这个会话，例如“自 周二 2026-11-10, 19:56 起的会话（进行中）”或“（已结束）”。会话可以跨过午夜。

在它下方，有一行状态会显示炉石传说是否正在写入追踪器读取的游戏日志：“游戏日志（Power.log）：已开启”。如果追踪器必须在炉石传说运行时开启日志，这一行会以红字请你重启一次炉石传说。如果它无法开启日志，这一行会以红字说明，并给出文件名（请参阅 [INSTALL.md](INSTALL.md#troubleshooting)）。

<a id="tabs"></a>
### 标签页

**概览**

| 信息卡 | 含义 |
|---|---|
| “经验值” | 这个时段获得的经验值 |
| “经验值时间” | 计入经验值的时间 |
| “游戏时间（含起始手牌）” | 在对局中的时间，包括选择起始手牌 |
| “在线时间” | 炉石传说运行的时间。见下文。 |
| “对局” | 对局数，含胜场和负场 |
| “每小时经验值” | 每小时经验值时间的经验值 |
| “每在线小时经验值” | 每小时在线时间的经验值，因此包括菜单和排队 |
| “胜率” | 获胜对局所占的比例 |
| “活动经验值” | 这个时段的活动经验值；只有在活动期间进行过对局时才会显示 |

在线时间按炉石传说会话计算：从炉石传说启动到最后一局对局结束为止。炉石传说运行期间，会一直计算到现在。只有在这个时段内至少有一局对局的会话才会计入。

没有实测速率的模式（例如酒馆战棋）的对局会不带经验值保存。它们显示在“对局”中，并计入游戏时间和在线时间，但不计入其他数值块和图表。

**损失的经验值**

| 信息卡 | 含义 |
|---|---|
| “挂机回合” | 因挂机回合而损失的经验值：没有任何操作、也没点“结束回合”就时间耗尽的回合，以及之后的对手回合 |
| “不到 1 分钟的对局” | 公式会为不到 60 秒的对局算出、但游戏不会给的经验值 |
| “对局以外的时间” | 花在对局以外的在线时间（菜单、排队、休息），按你这个时段的每小时经验值计算 |

**对局**

这个时段的所有对局，最新的在最前面：日期、开始、模式、结果、经验值时间、总时间、经验值、活动经验值、挂机回合和对手职业。点击列标题即可排序。

**图表**

两条曲线使用同一条时间轴。时间轴始终覆盖整个时段，所以没有对局的小时或日期也会显示：

| 时段 | 时间轴 |
|---|---|
| “本次会话” | 从会话开始到结束的每个小时，进行中时则到现在 |
| “今天” | 当天的 24 个小时 |
| “本周” | 周一到周日 |
| “本赛季” | 本月的每一天 |
| “最近 30 天” | 最近 30 天，包括今天 |
| “全部” | 从记录中第一局对局起的每一天 |

| 曲线 | 含义 |
|---|---|
| “获得的经验值”（金色） | 每个小时或每天开始的对局所获得的经验值。没有对局的区间为 0。 |
| “每小时经验值”（蓝色） | 每个小时或每天的速度：经验值除以经验值时间。只有有对局的区间才有数据点。虚线是整个时段的平均值。 |

对局会计入它开始的那个小时或那一天。

<a id="game-history-file"></a>
## 对局记录文件

每局结束的对局都会添加到一个 CSV 文件中：

```
%APPDATA%\HearthstoneXpTracker\hs_games.csv
```

这个文件用逗号分隔字段，并用英文句点作为小数点。时间为本地时间。

| 列 | 内容 |
|---|---|
| `Session` | 这个会话的炉石传说日志文件夹名称，例如 `Hearthstone_2026_11_08_09_10_51` |
| `Start` | 第一个回合的开始时间，`yyyy-MM-ddTHH:mm:ss.fff` |
| `End` | 对局的结束时间，格式相同 |
| `Mode` | 游戏模式，例如 `Ranked` |
| `Format` | 赛制，例如 Standard 或 Wild；如果该模式没有赛制则为空 |
| `Result` | 例如 `Win` 或 `Loss` |
| `XpSeconds` | 计入经验值的时间 |
| `PlaySeconds` | 从第一个回合到结束的时间，包括挂机回合 |
| `WithMulliganSeconds` | 包括选择起始手牌在内的时间 |
| `AfkTurns` | 自己的挂机回合数 |
| `Xp` | 追踪器计算的经验值；没有实测速率的模式则为空 |
| `Deck` | 套牌名称，仅限以前的 HDT 插件记录的对局；较新的对局则为空 |
| `PlayerClass` | 你的职业 |
| `OpponentClass` | 对手的职业 |
| `EventXp` | 追踪器计算的活动经验值；非活动期间的对局则为空。没有这一列的旧版本文件仍然可以读取，下一局对局时会添加这一列。 |
| `XpBonus` | 对局当时适用的炉石通行证经验值加成百分比，例如 `15`；没有通行证时为 `0`。没有这一列的旧文件会按 `0` 读取。 |

`Xp` 列是追踪器根据经验值时间计算出来的。游戏本身不会记录经验值。面板打开时，追踪器会用当前的速率重新计算所有已保存对局的经验值，所以修正后的速率也会修正旧的对局。每局对局都保留自己的 `XpBonus`，所以之后更改通行证或等级，不会改变旧的对局。

从同一个日志读取两次的对局只会保存一次。安装新版本时，这个文件会保留。每次启动时，追踪器还会从以前的 HDT 插件的记录中，添加它还没有的对局（请参阅 [INSTALL.md](INSTALL.md#coming-from-the-hdt-plugin)）。

<a id="privacy"></a>
## 隐私

- 对局记录和设置都保存在你的电脑上。追踪器不会上传任何内容。
- 唯一的网络请求是更新检查。追踪器启动时，会向 GitHub 询问一次是否有新版本。这个请求只会发送程序名称和版本，例如 `HearthstoneXpTracker/0.2.0`。和任何网络请求一样，GitHub 会看到你的 IP 地址。
- 要关闭更新检查，请在面板中取消勾选“启动追踪器时检查更新”。这项设置保存在 `%APPDATA%\HearthstoneXpTracker\settings.ini` 中。
- 追踪器只读取炉石传说的日志。它不会读取游戏的内存，也不会更改游戏文件。它只会写入自己的数据文件夹，以及一次性写入 `log.config` 的 `[Power]` 部分（请参阅 [INSTALL.md](INSTALL.md#requirements)）。
