# Установка

> Текст переведён с помощью машинного перевода. Если он расходится с [английской версией](../INSTALL.md), действует английская версия. Исправления приветствуются: [создайте issue](https://github.com/critterbyte/hearthstone_xp_tracker/issues/new/choose).

<a id="requirements"></a>
## Требования

- Windows 10 или 11. Трекеру нужен .NET Framework 4.7.2, который входит в обе системы.
- Hearthstone

Трекер читает файл `Power.log` игры Hearthstone. Hearthstone ведёт этот журнал, только если он включён в собственном файле настроек игры, `%LOCALAPPDATA%\Blizzard\Hearthstone\log.config`. Трекер включает его при первом запуске: он добавляет раздел `[Power]` и больше ничего в файле не меняет. Перед этим изменением он сохраняет копию старого файла как `log.config.bak`.

<a id="install"></a>
## Установка

1. Скачайте ZIP-файл последнего выпуска со [страницы Releases](https://github.com/critterbyte/hearthstone_xp_tracker/releases), например `HearthstoneXpTracker-0.2.0.zip`.
2. Щёлкните ZIP-файл правой кнопкой мыши, выберите *Свойства* (*Properties*) и отметьте *Разблокировать* (*Unblock*), если этот пункт есть.
3. Распакуйте ZIP в любую папку, например *Документы* (*Documents*). Появится папка `HearthstoneXpTracker` с такими файлами:
   - `HearthstoneXpTracker.exe`: сам трекер
   - `HearthstoneXpTracker.exe.config`, `XpTracker.Core.dll`, `LiveCharts.dll`, `LiveCharts.Wpf.dll` и `Newtonsoft.Json.dll`: нужны трекеру
   - `INSTALL.txt`, `LICENSE.txt` и `THIRD-PARTY-NOTICES.txt`

   Выберите папку, в которую у вас есть права на запись. В папке *Program Files* для каждого обновления нужны права администратора.
4. Запустите `HearthstoneXpTracker.exe`. Если Windows покажет «Система Windows защитила ваш компьютер» (*Windows protected your PC*), выберите *Подробнее* (*More info*), а затем *Выполнить в любом случае* (*Run anyway*). Трекер пока не подписан, поэтому Windows его не знает.
5. Откроется панель, а в области уведомлений (*notification area*) в правом нижнем углу панели задач появится золотой значок «XP». Он может быть скрыт за маленькой стрелкой (^).

Если при первом запуске трекера Hearthstone уже был запущен, перезапустите его один раз. Hearthstone читает `log.config` только при запуске.

Оверлей появится с первым ходом вашего следующего матча. Что он показывает, описано в [USAGE.md](USAGE.md).

Все файлы должны оставаться вместе в одной папке. При первом запуске полоса вверху панели один раз спросит, добавить ли трекер в меню «Пуск». Чтобы трекер запускался автоматически при входе в Windows, отметьте в панели «Запускать вместе с Windows». Если позже вы переместите папку, запустите трекер один раз из нового места: он обновит ярлык в меню «Пуск» и запись автозапуска.

Для каждого выпуска указана контрольная сумма SHA-256 ZIP-файла. Чтобы проверить загрузку, выполните в PowerShell `Get-FileHash HearthstoneXpTracker-0.2.0.zip` и сравните результат.

<a id="coming-from-the-hdt-plugin"></a>
## Переход с плагина HDT

До версии 0.1.2 трекер был плагином для HDT. HDT прекращает поддержку плагинов 30 ноября 2026 года, поэтому трекер теперь отдельная программа с тем же оверлеем и той же панелью.

- **Ваши данные переносятся.** При каждом запуске трекер добавляет из истории плагина (`%APPDATA%\HearthstoneDeckTracker\XpTracker\hs_games.csv`) матчи, которых у него ещё нет. Кроме того, он один раз перенимает настройки плагина, если своих у него ещё нет. Файлы плагина только читаются и никогда не изменяются.
- **Отключите плагин.** В HDT откройте *Settings* (значок шестерёнки справа на верхней панели) *→ Tracker → Plugins* и отключите **Hearthstone XP Tracker**. Иначе два оверлея будут показывать одни и те же числа. Можно также удалить папку `%APPDATA%\HearthstoneDeckTracker\Plugins\HearthstoneXpTracker`.
- **Пока без названий колод.** Названия колод предоставлял HDT, поэтому вкладка *Колоды* и столбец колоды пока убраны. У старых матчей названия колод сохраняются в файле истории.

<a id="update"></a>
## Обновление

Когда выходит новая версия, трекер сообщает об этом (см. [USAGE.md](USAGE.md#update-hint)). Чтобы обновиться:

1. Скачайте ZIP-файл нового выпуска и разблокируйте его (см. выше).
2. Закройте трекер: щёлкните золотой значок «XP» правой кнопкой мыши и выберите «Выход».
3. Снова распакуйте ZIP в ту же папку и замените старые файлы.
4. Запустите `HearthstoneXpTracker.exe`.

История матчей и настройки сохраняются. Они хранятся в другой папке (см. ниже).

Чтобы вернуться к более старой версии, сделайте то же самое с её ZIP-файлом.

<a id="uninstall"></a>
## Удаление

1. В панели снимите флажки «Запускать вместе с Windows» и «Ярлык в меню «Пуск»».
2. Закройте трекер: щёлкните золотой значок «XP» правой кнопкой мыши и выберите «Выход».
3. Удалите распакованную папку `HearthstoneXpTracker`.

Трекер хранит ваши данные в `%APPDATA%\HearthstoneXpTracker`:

| Файл | Содержимое |
|---|---|
| `hs_games.csv` | История матчей |
| `settings.ini` | Настройки |
| `xptracker.log` | Непредвиденные ошибки, если они были |

Удалите и эту папку, если не хотите сохранять данные.

Раздел `[Power]` остаётся в `log.config`, потому что его могут использовать и другие программы. Он только заставляет Hearthstone вести журнал. Чтобы вернуть файл в прежнее состояние, замените `log.config` файлом `log.config.bak`.

<a id="troubleshooting"></a>
## Устранение неполадок

**Windows показывает «Система Windows защитила ваш компьютер» (*Windows protected your PC*).**

- Выберите *Подробнее* (*More info*), а затем *Выполнить в любом случае* (*Run anyway*). Windows показывает это сообщение для программ, которые ещё не знает. У трекера открытый исходный код; вы можете прочитать код на GitHub и проверить контрольную сумму SHA-256 ZIP-файла.

**При запуске трекера ничего не происходит.**

- Возможно, он уже запущен. Повторный запуск открывает панель уже работающего трекера. Найдите золотой значок «XP» в области уведомлений, в том числе за маленькой стрелкой (^).
- Проверьте, что все файлы из ZIP лежат в одной папке и что ZIP был разблокирован (см. [Установка](#install)).

**Оверлей не появляется.**

- Оверлей показывается только в режимах Рейтинг, Обычный, Потасовка в таверне и Арена. Другие режимы пока не измеряются.
- Во время выбора стартовой руки оверлей скрыт. Он появляется с первым ходом.
- Оверлей показывается, только пока Hearthstone — активное окно. Щёлкните один раз в окне игры.
- Посмотрите на строку состояния на панели, под кнопками периодов. Там должно быть написано «Журнал игры (Power.log): включён». Если она просит перезапустить Hearthstone, сделайте это.

**Панель сообщает, что не удалось включить журнал игры.**

- Трекер не смог записать `%LOCALAPPDATA%\Blizzard\Hearthstone\log.config`. Закройте Hearthstone, откройте файл в *Блокноте* (*Notepad*) (создайте его, если его нет), добавьте в конец эти строки и сохраните файл:

  ```ini
  [Power]
  LogLevel=1
  FilePrinting=True
  ConsolePrinting=False
  ScreenPrinting=False
  Verbose=True
  ```

**Что-то другое работает не так.**

Пожалуйста, [создайте issue](https://github.com/critterbyte/hearthstone_xp_tracker/issues/new/choose) и укажите версию трекера (панель показывает её в правом верхнем углу), свою версию Windows и то, что вы ожидали увидеть. Если существует файл `%APPDATA%\HearthstoneXpTracker\xptracker.log`, помогут и его последние строки.
