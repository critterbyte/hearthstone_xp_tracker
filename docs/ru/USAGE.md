# Использование

> Текст переведён с помощью машинного перевода. Если он расходится с [английской версией](../USAGE.md), действует английская версия. Исправления приветствуются: [создайте issue](https://github.com/critterbyte/hearthstone_xp_tracker/issues/new/choose).

Трекер работает в фоне, с золотым значком «XP» в области уведомлений (*notification area*) в правом нижнем углу панели задач. Он состоит из трёх частей:

- **оверлей** в игре
- окно **панели**
- файл **истории матчей**

Тексты в кавычках, например «Время опыта:», — это тексты, которые показывает трекер.

<a id="overlay"></a>
## Оверлей

Оверлей — это небольшое окошко в правом нижнем углу, над кнопкой настроек Hearthstone (шестерёнка в правом нижнем углу). В панели его можно вместо этого разместить в левом нижнем углу, над вашим портретом («You» с вашим рангом). Подписи слева. Значения справа, в синих полосках.

Оверлей показывается, только пока Hearthstone — активное окно. Он никогда не забирает фокус, и каждый щелчок проходит сквозь него в игру.

Оверлей показывается только в режимах **Рейтинг, Обычный, Потасовка в таверне и Арена**. Другие режимы пока не измеряются, поэтому там трекер ничего не показывает. Потасовка в таверне против компьютера (PvE, например против Хозяина таверны) не даёт опыта, поэтому оверлей показывает там «+0».

<a id="during-a-game"></a>
### Во время матча

Строки появляются с первым ходом. Во время выбора стартовой руки оверлей скрыт.

| Строка | Значение |
|---|---|
| «Время опыта:» | Время, которое уже засчитано для опыта, в минутах и секундах |
| «При победе:» | Опыт, который вы получите, если победите сейчас |
| «При поражении:» | Опыт, который вы получите, если проиграете или сдадитесь сейчас |

У времени опыта может быть пометка:

| Пометка | Значение |
|---|---|
| «(пауза)» | Ваш ход истёк без единого действия. Этот ход и следующий ход противника не засчитываются, поэтому время опыта откатилось назад и ждёт. Оно снова пойдёт в ваш следующий ход. |
| «(макс.)» | Время опыта достигло 30 минут. Дальнейшее время больше не даёт опыта. |

Во время события Hearthstone включите на панели «Идёт событие (показывать опыт события)». Тогда оверлей показывает ещё одну строку, в реальном времени и в итогах после матча:

| Строка | Значение |
|---|---|
| «Опыт события:» | Опыт события на данный момент, с красным кристаллом: одна единица за минуту времени опыта (см. [FORMULA.md](../FORMULA.md#event-xp)). Не зависит от результата. |

Выключите эту опцию, когда событие закончится.

Если на панели включён «Пропуск завсегдатая (бонус к опыту)», значения «При победе:», «При поражении:» и «Получено:» включают бонус пропуска для вашего уровня на Ленте наград. Опыт события бонуса не получает.

Последние две строки показывают урон, в реальном времени и в итогах после матча. Отключить их можно опцией «Показывать урон в оверлее» на панели.

| Строка | Значение |
|---|---|
| «Урон всего:» | Весь урон, который ваша сторона нанесла на данный момент герою и существам противника: ваши атаки, атаки ваших существ, заклинания, оружие, сила героя и другие эффекты. Каждое попадание учитывается с тем значением, которое показывает игра, даже если оно больше здоровья цели или приходится на броню. Урон своему герою или своим существам не учитывается, как и урон без источника, например от усталости. Попадание по Божественному щиту равно 0. |
| «Урон герою:» | Часть «Урон всего:», пришедшаяся на героя противника, включая часть, поглощённую бронёй |

Урон считывается, когда сервер подтверждает действие, поэтому он может вырасти чуть раньше анимации на поле.

Пока время опыта меньше 60 секунд, оба значения опыта показывают «+0». Матчи короче минуты не дают опыта. Правила описаны в [FORMULA.md](../FORMULA.md).

Если запустить трекер посреди матча, он всё равно прочитает матч с самого начала.

<a id="after-a-game"></a>
### После матча

После матча оверлей показывает итоги до выбора стартовой руки в следующем матче:

| Строка | Значение |
|---|---|
| «Последний матч:» | Победа или Поражение |
| «Время опыта:» | Время, засчитанное для опыта |
| «Общее время:» | Весь матч, включая выбор стартовой руки |
| «Получено:» | Опыт, который дал матч |

<a id="update-hint"></a>
### Уведомление об обновлении

Когда выходит новая версия трекера, оверлей показывает ещё одну строку, пока не идёт матч:

| Строка | Значение |
|---|---|
| «Доступно обновление:» | Номер новой версии, например 0.2.0 |

Панель показывает ссылку на страницу загрузки. Как обновиться, описано в [INSTALL.md](INSTALL.md#update).

<a id="dashboard"></a>
## Панель

Окно панели называется «HS XP Tracker». Оно открывается при запуске трекера. Чтобы открыть его снова:

- щёлкните золотой значок «XP» в области уведомлений, или
- щёлкните значок правой кнопкой мыши и выберите «Панель опыта», или
- снова запустите `HearthstoneXpTracker.exe`.

Если закрыть панель, трекер и оверлей продолжают работать. Чтобы завершить работу трекера, щёлкните значок правой кнопкой мыши и выберите «Выход».

<a id="toolbar"></a>
### Панель инструментов

| Элемент | Значение |
|---|---|
| «Сеанс» | Матчи текущего сеанса Hearthstone, от запуска игры до её закрытия. После закрытия Hearthstone последний сеанс остаётся видимым до следующего запуска. Этот период панель показывает при открытии. |
| «Сегодня» | Матчи с полуночи |
| «Эта неделя» | Матчи с понедельника, 00:00 |
| «Этот сезон» | Матчи с 1-го числа месяца. Рейтинговые сезоны в Hearthstone длятся календарный месяц. |
| «Последние 30 дней» | Матчи за последние 30 дней, включая сегодня |
| «За всё время» | Все матчи в истории |
| «Обновить» | Заново прочитать историю |
| «Открыть папку данных» | Открыть папку с файлом истории в Проводнике Windows |
| «Язык (Language)» | Язык оверлея, панели и меню значка. По умолчанию английский. Изменение применяется сразу; панель открывается заново на новом языке. В других языках подпись сохраняет английское слово, например «Язык (Language)». |
| «Положение оверлея» | Где находится оверлей: «Справа, над кнопкой настроек» (по умолчанию) или «Слева, над вашим портретом», так правая сторона остаётся свободной, например для списка колоды Hearthstone Deck Tracker. Оверлей перемещается сразу. |
| «Идёт событие (показывать опыт события)» | Включите во время события Hearthstone: оверлей показывает опыт события, а новые матчи сохраняют его. Трекер не может определить, когда идёт событие, поэтому по умолчанию эта опция выключена; пока она выключена, под ней напоминает об этом короткая подсказка. |
| «Пропуск завсегдатая (бонус к опыту)» | Включите, если у вас есть Пропуск завсегдатая текущего дополнения. Бонус рассчитывается, а не измеряется: с пропуском показанный опыт может отличаться на 1 единицу за матч (см. [FORMULA.md](../FORMULA.md#tavern-pass)). |
| «Уровень» с «−», числом и «+» | Ваш уровень на Ленте наград. Нажмите «−» или «+» или введите число. Строка ниже показывает бонус и следующий порог, например «+10% к опыту, ещё 2 ур. до 15%». Бонус составляет 10%, с 20-го уровня 15% и с 70-го уровня 20% (см. [FORMULA.md](../FORMULA.md#tavern-pass)). Обновите уровень, когда пройдёте 20-й или 70-й уровень. |
| «Показывать урон в оверлее» | Показать или скрыть строки «Урон всего:» и «Урон герою:». По умолчанию включено. |
| «Проверять обновления при запуске трекера» | Включить или выключить проверку обновлений. См. [Конфиденциальность](#privacy). |
| «Запускать вместе с Windows» | Запускает трекер при входе в Windows. Тогда он появляется только в области уведомлений; щёлкните значок, чтобы открыть панель. По умолчанию выключено. Отключить автозапуск можно и в диспетчере задач, в разделе *Автозагрузка приложений* (*Startup apps*). |
| «Ярлык в меню «Пуск»» | Добавляет «Hearthstone XP Tracker» в меню «Пуск» или удаляет его оттуда. При первом запуске полоса вверху панели один раз спросит об этом. |

Завершённый матч сам появляется в открытой панели. Нажимать «Обновить» не нужно.

Для «Сеанс» строка под панелью инструментов называет сеанс, например «Сеанс с вт 2026-11-10, 19:56 (идёт)» или «(завершён)». Сеанс может продолжаться после полуночи.

Под ней строка состояния показывает, ведёт ли Hearthstone журнал игры, который читает трекер: «Журнал игры (Power.log): включён». Если трекеру пришлось включить журнал, когда Hearthstone был запущен, строка красным просит один раз перезапустить Hearthstone. Если включить журнал не удалось, строка сообщает об этом красным и называет файл (см. [INSTALL.md](INSTALL.md#troubleshooting)).

<a id="tabs"></a>
### Вкладки

**Обзор**

| Плитка | Значение |
|---|---|
| «Опыт» | Опыт, полученный за период |
| «Время опыта» | Время, засчитанное для опыта |
| «Время игры со стартовой рукой» | Время в матчах, включая выбор стартовой руки |
| «Время в сети» | Время, пока был запущен Hearthstone. См. ниже. |
| «Матчи» | Число матчей, с победами и поражениями |
| «Опыт в час» | Опыт за час времени опыта |
| «Опыт за час в сети» | Опыт за час времени в сети, то есть включая меню и очередь |
| «Доля побед» | Доля выигранных матчей |
| «Опыт события» | Опыт события за период; показывается, только если матчи игрались во время события |

Время в сети считается по сеансам Hearthstone: от запуска Hearthstone до конца последнего матча. Пока Hearthstone запущен, оно считается до текущего момента. Учитываются только сеансы, в которых за период был хотя бы один матч.

Матчи в режимах без измеренных ставок, например Поля сражений, сохраняются без опыта. Они показаны в «Матчи» и учитываются во времени игры и времени в сети, но не в остальных плитках и графиках.

**Потерянный опыт**

| Плитка | Значение |
|---|---|
| «Ходы AFK» | Опыт, потерянный из-за ходов AFK: ходов без единого действия, которые истекли без «ЗАКОНЧИТЬ», и следующих за ними ходов противника |
| «Матчи короче 1 минуты» | Опыт, который формула дала бы за матчи короче 60 секунд, но который игра не начисляет |
| «Время вне матчей» | Время в сети вне матчей (меню, очередь, перерывы), оценённое по вашему опыту в час за период |

**Матчи**

Все матчи за период, сначала новые: дата, начало, режим, итог, время опыта, общее время, опыт, опыт события, ходы AFK и класс противника. Щёлкните заголовок столбца, чтобы отсортировать.

**Графики**

Две кривые на одной оси времени. Ось всегда охватывает весь период, поэтому часы или дни без матчей тоже видны:

| Период | Ось времени |
|---|---|
| «Сеанс» | каждый час от начала сеанса до его конца или до текущего момента, пока он идёт |
| «Сегодня» | 24 часа дня |
| «Эта неделя» | с понедельника по воскресенье |
| «Этот сезон» | каждый день месяца |
| «Последние 30 дней» | последние 30 дней, включая сегодня |
| «За всё время» | каждый день с первого матча в истории |

| Кривая | Значение |
|---|---|
| «Получено опыта» (золотая) | Опыт матчей, начатых в каждый час или в каждый день. Шаги без матчей равны 0. |
| «Опыт в час» (синяя) | Темп в каждый час или в каждый день: опыт, делённый на время опыта. Точку имеют только шаги с матчами. Пунктирная линия — среднее за весь период. |

Матч учитывается в том часе или дне, в котором он начался.

<a id="game-history-file"></a>
## Файл истории матчей

Каждый завершённый матч добавляется в CSV-файл:

```
%APPDATA%\HearthstoneXpTracker\hs_games.csv
```

В файле поля разделяются запятыми, а десятичным разделителем служит точка. Время указано местное.

| Столбец | Содержимое |
|---|---|
| `Session` | Имя папки журналов Hearthstone для сеанса, например `Hearthstone_2026_11_08_09_10_51` |
| `Start` | Начало первого хода, `yyyy-MM-ddTHH:mm:ss.fff` |
| `End` | Конец матча, тот же формат |
| `Mode` | Режим игры, например `Ranked` |
| `Format` | Формат, например Стандартный или Вольный; пусто, если у режима нет формата |
| `Result` | Например, `Win` или `Loss` |
| `XpSeconds` | Время, засчитанное для опыта |
| `PlaySeconds` | Время от первого хода до конца, включая ходы AFK |
| `WithMulliganSeconds` | Время, включая выбор стартовой руки |
| `AfkTurns` | Число собственных ходов AFK |
| `Xp` | Опыт, рассчитанный трекером; пусто для режимов без измеренных ставок |
| `Deck` | Название колоды, только для матчей, записанных прежним плагином HDT; пусто для новых матчей |
| `PlayerClass` | Ваш класс |
| `OpponentClass` | Класс противника |
| `EventXp` | Опыт события, рассчитанный трекером; пусто для матчей вне событий. Файлы старых версий без этого столбца по-прежнему читаются, а столбец добавляется со следующим матчем. |
| `XpBonus` | Бонус к опыту от Пропуска завсегдатая в процентах, действовавший во время матча, например `15`; `0` без пропуска. Старые файлы без этого столбца читаются как `0`. |

Столбец `Xp` трекер рассчитывает по времени опыта. Сама игра не записывает опыт в журнал. При открытии панели трекер заново рассчитывает опыт всех сохранённых матчей по текущим ставкам, поэтому исправленная ставка исправляет и старые матчи. Каждый матч хранит собственный `XpBonus`, поэтому последующее изменение пропуска или уровня не меняет старые матчи.

Матч, прочитанный из одного и того же журнала дважды, сохраняется только один раз. При установке новой версии файл сохраняется. Кроме того, при каждом запуске трекер добавляет из истории прежнего плагина HDT матчи, которых у него ещё нет (см. [INSTALL.md](INSTALL.md#coming-from-the-hdt-plugin)).

<a id="privacy"></a>
## Конфиденциальность

- История матчей и настройки остаются на вашем компьютере. Трекер ничего не отправляет.
- Единственный сетевой запрос — проверка обновлений. При запуске трекер один раз спрашивает у GitHub, есть ли новый выпуск. Запрос передаёт только название и версию программы, например `HearthstoneXpTracker/0.2.0`. Как и при любом веб-запросе, GitHub видит ваш IP-адрес.
- Чтобы отключить проверку обновлений, снимите на панели флажок «Проверять обновления при запуске трекера». Настройка хранится в `%APPDATA%\HearthstoneXpTracker\settings.ini`.
- Трекер только читает журнал Hearthstone. Он не читает память игры и не изменяет файлы игры. Он записывает только в собственную папку данных и один раз — раздел `[Power]` в `log.config` (см. [INSTALL.md](INSTALL.md#requirements)).
