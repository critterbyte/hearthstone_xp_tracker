# 使い方

> 機械翻訳を基にした翻訳です。[英語版](../USAGE.md)と異なる場合は、英語版が優先されます。修正を歓迎します: [Issue を作成](https://github.com/critterbyte/hearthstone_xp_tracker/issues/new/choose)。

このプラグインは 3 つの部分でできています。

- ゲーム内の**オーバーレイ**
- **ダッシュボード**ウィンドウ
- **試合履歴**ファイル

「XP時間:」のようにかぎかっこで囲んだ文字は、プラグインが表示する文字です。

<a id="overlay"></a>
## オーバーレイ

オーバーレイは、左下の自分の肖像（ランク付きの「You」）の上にある小さな枠です。ダッシュボードで、Hearthstone の設定ボタン（右下の歯車）の上に移動することもできます。左側にラベル、右側に青いバーで値が表示されます。

オーバーレイは**ランク戦、カジュアル、酒場の喧嘩、闘技場**でのみ表示されます。ほかのモードはまだ計測されていないため、プラグインは何も表示しません。コンピューター相手の酒場の喧嘩（PvE、例えば酒場のオヤジとの対戦）では XP がもらえないため、オーバーレイには「+0」と表示されます。

<a id="during-a-game"></a>
### 試合中

各行は最初のターンで表示されます。最初の手札の選択中は、オーバーレイは表示されません。

| 行 | 意味 |
|---|---|
| 「XP時間:」 | これまでに XP の対象になった時間（分と秒） |
| 「勝利時:」 | 今勝った場合にもらえる XP |
| 「敗北時:」 | 今負けるか敗北宣言した場合にもらえる XP |

XP 時間には注記が付くことがあります。

| 注記 | 意味 |
|---|---|
| 「(一時停止)」 | 何も行動せずに自分のターンの時間切れになりました。そのターンと相手の次のターンはカウントされないため、XP 時間は巻き戻って止まっています。自分の次のターンで再び進みます。 |
| 「(上限)」 | XP 時間が 30 分に達しました。これ以上時間がたっても XP は増えません。 |

Hearthstone のイベント中は、ダッシュボードで「イベント開催中（イベントXPを表示）」をオンにしてください。すると、オーバーレイに行が 1 つ増え、試合中と試合後のまとめに表示されます。

| 行 | 意味 |
|---|---|
| 「イベントXP:」 | これまでのイベント XP（赤いクリスタル付き）。XP 時間 1 分ごとに 1 です（[FORMULA.md](../FORMULA.md#event-xp) を参照）。勝敗には関係しません。 |

イベントが終わったらオフにしてください。

ダッシュボードで「酒場パス（XPボーナス）」をオンにすると、「勝利時:」「敗北時:」「獲得:」に、報酬レーンのレベルに応じたパスのボーナスが含まれます。イベント XP にはボーナスは付きません。

最後の 2 行はダメージを表示します。試合中と試合後のまとめに表示されます。ダッシュボードの「オーバーレイにダメージを表示」でオフにできます。

| 行 | 意味 |
|---|---|
| 「合計ダメージ:」 | これまでに自分の側が相手のヒーローとミニオンに与えたすべてのダメージです。自分の攻撃、自分のミニオンの攻撃、呪文、武器、ヒーローパワー、その他の効果が含まれます。各ヒットはゲームに表示される値で数え、対象の体力を超える場合やアーマーに当たる場合も同じです。自分のヒーローやミニオンへのダメージは数えません。疲労のように発生源のないダメージも数えません。聖なる盾へのヒットは 0 です。 |
| 「ヒーローへのダメージ:」 | 「合計ダメージ:」のうち相手のヒーローに当たった分です。アーマーが吸収した分も含みます。 |

ダメージはサーバーが行動を確定した時点で読み取るため、盤面のアニメーションより少し早く増えることがあります。

XP 時間が 60 秒未満の間は、どちらの XP 値も「+0」と表示されます。1 分未満の試合では XP はもらえません。ルールは [FORMULA.md](../FORMULA.md) を参照してください。

試合の途中で HDT を起動しても、プラグインは試合を最初から読み取ります。

<a id="after-a-game"></a>
### 試合後

試合が終わると、次の試合の最初の手札の選択まで、オーバーレイにまとめが表示されます。

| 行 | 意味 |
|---|---|
| 「前回の試合:」 | 「勝利」または「敗北」 |
| 「XP時間:」 | XP の対象になった時間 |
| 「合計時間:」 | 最初の手札を含む試合全体の時間 |
| 「獲得:」 | その試合でもらえた XP |

<a id="update-hint"></a>
### アップデートの通知

プラグインの新しいバージョンがあると、試合をしていない間、オーバーレイに行が 1 つ増えます。

| 行 | 意味 |
|---|---|
| 「アップデートあり:」 | 新しいバージョンの番号。例: 0.2.0 |

ダッシュボードにはダウンロードページへのリンクが表示されます。アップデートの方法は [INSTALL.md](INSTALL.md#update) を参照してください。

<a id="dashboard"></a>
## ダッシュボード

ダッシュボードのウィンドウ名は「HS XP Tracker」です。HDT で次のどちらかの方法で開きます。

- *Plugins* メニュー →「XPダッシュボード」
- *Settings*（上部バーの右にある歯車アイコン）*→ Tracker → Plugins* → プラグインの「XPダッシュボード」ボタン

<a id="toolbar"></a>
### ツールバー

| 操作 | 意味 |
|---|---|
| 「セッション」 | 現在の Hearthstone セッションの試合です。ゲームの起動から終了までが対象です。Hearthstone を閉じた後も、次に起動するまで最後のセッションが表示されます。ダッシュボードを開いたときに表示される期間です。 |
| 「今日」 | 午前 0 時以降の試合 |
| 「今週」 | 月曜日 00:00 以降の試合 |
| 「今シーズン」 | 月の 1 日以降の試合。Hearthstone のランク戦のシーズンは暦の 1 か月です。 |
| 「過去30日」 | 今日を含む過去 30 日の試合 |
| 「全期間」 | 履歴にあるすべての試合 |
| 「更新」 | 履歴を読み直します |
| 「データフォルダーを開く」 | 履歴ファイルのあるフォルダーを Windows のエクスプローラーで開きます |
| 「言語 (Language)」 | オーバーレイ、ダッシュボード、プラグインのメニュー項目の言語です。既定は英語です。変更はすぐに反映され、ダッシュボードは新しい言語で開き直します。英語以外の言語では、ラベルに英語の単語も残ります。例:「言語 (Language)」 |
| 「オーバーレイの位置」 | オーバーレイの表示位置です。「左（自分の肖像の上）」（既定。右側の HDT のデッキリストが隠れません）または「右（設定ボタンの上）」。すぐに移動します。 |
| 「イベント開催中（イベントXPを表示）」 | Hearthstone のイベント中にオンにします。オーバーレイにイベント XP が表示され、新しい試合に保存されます。 |
| 「酒場パス（XPボーナス）」 | 現在の拡張版の酒場パスを持っている場合にオンにします。ボーナスは計算値で、計測値ではありません。パスがある場合、表示される XP は 1 試合あたり 1 XP ずれることがあります（[FORMULA.md](../FORMULA.md#tavern-pass) を参照）。 |
| 「レベル」と「−」、数値、「+」 | 報酬レーンのレベルです。「−」か「+」をクリックするか、数値を入力します。下の行にボーナスと次の段階が表示されます。例:「XPボーナス10%、あと2レベルで15%」。ボーナスは 10%、レベル 20 から 15%、レベル 70 から 20% です（[FORMULA.md](../FORMULA.md#tavern-pass) を参照）。レベル 20 または 70 を超えたら、レベルを更新してください。 |
| 「オーバーレイにダメージを表示」 | 「合計ダメージ:」と「ヒーローへのダメージ:」の行を表示または非表示にします。既定はオンです。 |
| 「HDTの起動時にアップデートを確認」 | アップデートの確認をオンまたはオフにします。[プライバシー](#privacy) を参照してください。 |

終わった試合は、開いているダッシュボードに自動で表示されます。「更新」をクリックする必要はありません。

「セッション」では、ツールバーの下の行にセッションが表示されます。例:「火 2026-11-10, 19:56からのセッション（継続中）」または「（終了）」。セッションは午前 0 時をまたぐことがあります。

<a id="tabs"></a>
### タブ

**概要**

| タイル | 意味 |
|---|---|
| 「XP」 | 期間中に獲得した XP |
| 「XP時間」 | XP の対象になった時間 |
| 「プレイ時間（最初の手札を含む）」 | 最初の手札を含む、試合中の時間 |
| 「オンライン時間」 | Hearthstone が起動していた時間。下記を参照してください。 |
| 「試合」 | 試合数と勝敗数 |
| 「1時間あたりのXP」 | XP 時間 1 時間あたりの XP |
| 「オンライン1時間あたりのXP」 | オンライン時間 1 時間あたりの XP。メニューと待ち時間を含みます |
| 「勝率」 | 勝った試合の割合 |
| 「イベントXP」 | 期間中のイベント XP。イベント中に試合をした場合のみ表示されます |

オンライン時間は Hearthstone のセッションごとに数えます。Hearthstone の起動から最後の試合の終了までです。Hearthstone の起動中は、現在までを数えます。期間中に 1 試合以上あるセッションだけが対象です。

**デッキ**

デッキごとに 1 行です。試合数、勝率、XP、1 時間あたりの XP、平均試合時間が表示されます。1 時間あたりの XP が最も高いデッキがいちばん上です。

デッキ名は HDT 自体の統計から取得します。HDT が記録しなかった試合には「デッキの記録なし」と表示されます。

**失ったXP**

| タイル | 意味 |
|---|---|
| 「放置ターン」 | 放置ターンで失った XP。何も行動せず「ターン終了」も押さずに時間切れになったターンと、その後の相手のターンです |
| 「1分未満の試合」 | 60 秒未満の試合について計算式上は得られるはずの XP。ゲームでは支払われません |
| 「試合外の時間」 | 試合外で過ごしたオンライン時間（メニュー、待ち時間、休憩）。期間中の 1 時間あたりの XP で換算します |

**試合**

期間中のすべての試合が新しい順に並びます。日付、開始、モード、結果、XP 時間、合計時間、XP、イベント XP、放置ターン、デッキ、対戦相手のクラスです。列見出しをクリックすると並べ替えられます。

**グラフ**

同じ時間軸に 2 本の曲線を表示します。時間軸は常に期間全体を表すため、試合のない時間や日も表示されます。

| 期間 | 時間軸 |
|---|---|
| 「セッション」 | セッションの開始から終了まで（継続中は現在まで）の 1 時間ごと |
| 「今日」 | その日の 24 時間 |
| 「今週」 | 月曜日から日曜日まで |
| 「今シーズン」 | その月の毎日 |
| 「過去30日」 | 今日を含む過去 30 日 |
| 「全期間」 | 履歴の最初の試合以降の毎日 |

| 曲線 | 意味 |
|---|---|
| 「獲得XP」（金色） | 各時間または各日に始まった試合の XP。試合のない区間は 0 です。 |
| 「1時間あたりのXP」（青） | 各時間または各日のペース: XP を XP 時間で割った値です。試合のある区間にだけ点があります。破線は期間全体の平均です。 |

試合は、開始した時間または日に数えます。

<a id="game-history-file"></a>
## 試合履歴ファイル

終わった試合はすべて CSV ファイルに追加されます。

```
%APPDATA%\HearthstoneDeckTracker\XpTracker\hs_games.csv
```

このファイルは、項目の区切りにカンマ、小数点にドットを使います。時刻はローカル時刻です。

| 列 | 内容 |
|---|---|
| `Session` | そのセッションの Hearthstone のログフォルダー名。例: `Hearthstone_2026_11_08_09_10_51` |
| `Start` | 最初のターンの開始。`yyyy-MM-ddTHH:mm:ss.fff` |
| `End` | 試合の終了。形式は同じです |
| `Mode` | ゲームモード。例: `Ranked` |
| `Format` | フォーマット。例: Standard または Wild。フォーマットのないモードでは空です |
| `Result` | 例: `Win` または `Loss` |
| `XpSeconds` | XP の対象になった時間 |
| `PlaySeconds` | 最初のターンから終了までの時間（放置ターンを含む） |
| `WithMulliganSeconds` | 最初の手札を含む時間 |
| `AfkTurns` | 自分の放置ターンの数 |
| `Xp` | プラグインが計算した XP。レートが計測されていないモードでは空です |
| `Deck` | HDT のデッキ名 |
| `PlayerClass` | 自分のクラス |
| `OpponentClass` | 対戦相手のクラス |
| `EventXp` | プラグインが計算したイベント XP。イベント外の試合では空です。この列のない古いバージョンのファイルも読み込めます。列は次の試合で追加されます。 |
| `XpBonus` | 試合をしたときに適用されていた酒場パスの XP ボーナス（パーセント）。例: `15`。パスがない場合は `0`。この列のない古いファイルは `0` として読み込みます。 |

`Xp` 列は、プラグインが XP 時間から計算したものです。ゲーム自体は XP をログに記録しません。ダッシュボードを開くと、プラグインは保存されているすべての試合の XP を現在のレートで計算し直します。そのため、レートが修正されると古い試合も直ります。各試合は自分の `XpBonus` を持ち続けるため、後でパスやレベルを変えても古い試合は変わりません。

同じログから 2 回読み込んだ試合は、1 回だけ保存されます。プラグインの新しいバージョンをインストールしても、ファイルは残ります。

<a id="privacy"></a>
## プライバシー

- 試合の履歴と設定はあなたのコンピューターに残ります。プラグインは何もアップロードしません。
- ネットワークへのリクエストはアップデートの確認だけです。HDT の起動時に、プラグインは新しいリリースがあるかを GitHub に 1 回問い合わせます。リクエストで送るのはプラグイン名とバージョンだけです。例: `HearthstoneXpTracker/0.1.0`。ほかのウェブリクエストと同じく、GitHub にはあなたの IP アドレスが見えます。
- アップデートの確認をオフにするには、ダッシュボードで「HDTの起動時にアップデートを確認」のチェックを外します。この設定は `%APPDATA%\HearthstoneDeckTracker\XpTracker\settings.ini` に保存されます。
