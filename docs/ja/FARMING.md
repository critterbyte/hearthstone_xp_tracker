# XP をもっと稼ぐには

> 機械翻訳を基にした翻訳です。[英語版](../FARMING.md)と異なる場合は、英語版が優先されます。修正を歓迎します: [Issue を作成](https://github.com/critterbyte/hearthstone_xp_tracker/issues/new/choose)。

1 時間あたりの報酬レーンの XP を増やすための、ルールに沿ったヒントです。内容は [XP の計算式](../FORMULA.md) に基づいています。記述には、計算式のページと同じ印を付けています。

- **計測:** このプロジェクトで確認したことです。
- **[n] による:** このページの最後にある出典によるものです。

プラグインのダッシュボードを見ると、XP の行方が分かります。まずは「失ったXP」タブを見るのがおすすめです（[USAGE.md](USAGE.md#tabs) を参照）。

<a id="play-fair"></a>
## フェアにプレイする

このページでは、普通に効率よくプレイする方法を扱います。ボット、勝敗の取引、アカウントの共有など、ゲームのルールを回避する方法は Blizzard の規約に違反し、アカウントが停止されることがあります。ここでは扱いません。

<a id="choose-the-mode"></a>
## モードを選ぶ

| モード | 勝利 | 敗北 |
|---|---:|---:|
| ランク戦（スタンダードとワイルド） | 470 XP/時 | 336 XP/時 |
| カジュアルと酒場の喧嘩 | 336 XP/時 | 240 XP/時 |

- **計測:** ランク戦は、カジュアルや酒場の喧嘩の 1.40 倍の XP がもらえます。カジュアルの勝利は、ランク戦の敗北と同じです。
- **計測:** スタンダードとワイルドは同じです。楽しめるフォーマットや、勝ちやすいフォーマットを選んでください。
- **計測:** 勝利は敗北の 1.40 倍です。勝率が大事なので、勝てるデッキを使ってください。
- **[1] による:** バトルグラウンドは 1 時間あたり約 300 XP です。このプロジェクトでは計測していません。

<a id="do-not-go-afk"></a>
## 放置しない

- **計測:** 何も行動せずに自分のターンの時間切れになると、そのターン**と**相手の次のターンでは XP がもらえません。
- 出せるものがないときは、**「ターン終了」**をクリックしてください。行動しなかったターンでも、自分で終了すればカウントされます。
- カードを 1 枚でも出すか、攻撃するか、ヒーローパワーを使えば、タイマーが切れてもそのターンはカウントされます。
- **計測:** **相手**が放置しても、あなたは何も失いません。相手が何もしないターンも、あなたにとってはすべてカウントされます。

<a id="mind-the-60-second-minimum"></a>
## 60 秒の最低時間に注意する

- **計測:** XP 時間が 60 秒未満の試合では、XP は**まったく**もらえません。少しももらえません。相手が早く敗北宣言した試合も同じです。
- 開始直後に敗北宣言すると、その試合では何ももらえません。

<a id="conceding"></a>
## 敗北宣言

- **計測:** 敗北宣言しても余計な損はありません。プレイした時間に応じた敗北時のレートでもらえます。
- **計測:** 負けている試合でも、続いている間は敗北時のレートでもらえます。そのため、プレイを続けても時間の無駄にはなりません。
- **計測:** 新しい試合を始めるたびに、XP にならない時間がかかります。1 試合の終了から次の試合の最初のターンまで約 1:07（10 回の平均）、さらに最初の手札に約 35 秒です。次の試合のほうが良くなりそうなとき、例えば勝てる試合をしたいときは、敗北宣言したほうが得です。

<a id="game-length"></a>
## 試合の長さ

- **計測:** 1 秒あたりの XP は一定です。ゆっくりプレイしても、試合時間 1 時間あたりの XP は増えません。1 試合あたりの XP が増えるだけです。
- 長い試合では、待ち時間や最初の手札に使う時間の割合が小さくなります。ただし、わざと時間稼ぎをするのはやめてください。相手に対して失礼です。
- **[2] による:** XP 時間には 1 試合あたり約 30 分の上限があります。それを超えた時間では何ももらえません。

<a id="quests-give-most-of-the-xp"></a>
## XP の大部分はクエストから

- **[3] による:** "Outside of the very hardcore player, majority of XP comes from quests."（非常にやり込むプレイヤーを除けば、XP の大部分はクエストから得られる。）
- **[4] による:** デイリークエストでは 900、1,000、または 1,500 XP がもらえます。ウィークリークエストでは 1,750 XP、確定で出るランク戦のウィークリークエスト（"Win 5 games of Hearthstone's Ranked Mode"、ランク戦で 5 回勝利）では 2,500 XP がもらえます。
- **[5] による:** 毎日、デイリークエストを 1 つとウィークリークエストを 1 つ入れ替えられます。入れ替えたクエストの進行状況は失われます。
- デイリークエスト 1 つは、ランク戦の試合の約 2～4 時間分に相当します。プレイしながらクエストを達成できるデッキとモードを選んでください。

<a id="tavern-pass"></a>
## 酒場パス

- **[6] による:** 酒場パスを買うとすぐに 10% の XP ボーナスが付き、報酬レーンのレベル 20 で 15%、レベル 70 で 20% になります。拡張版の期間が終わるまで続きます。
- **[7] による:** ボーナスは、どこから得た XP にも適用されます。
- 未計測: ボーナスが試合のレートにそのまま掛け算されるかどうか。計測はすべてパスなしで行いました。

<a id="track-size"></a>
## 報酬レーンの大きさ

- **[6] による:** 報酬レーンのレベル 1～100 には、合計で 155,200 XP が必要です。ボーナスレベルはレベル 400 まであり、それぞれ 50 ゴールドがもらえます。
- **[7] による:** 報酬レーンは、新しい拡張版が出るたびにリセットされます。
